## 문서 구조

이 문서는 네 section으로 구성됩니다.

- **Overview**: 모두를 위한 Canton 개념, architecture, protocol
- **App Development**: Developer를 위한 Daml과 API 기반 application 구축
- **Global Synchronizer**: Operator를 위한 Validator와 infrastructure 운영
- **Building Blocks**: Developer와 사용자를 위한 wallet, app, component, integration

각 section의 내용은 단계적으로 깊어지는 다음 model을 따릅니다.

- **Understand**: 모두를 위한 개념적 기초
- **Learn**: 실제 적용을 포함한 더 상세한 이해
- **Reference**: Protocol 동작 방식과 API에 관한 심층 문서

## 사전 지식

시작하기 전에 다음 경험이 있으면 좋습니다.

- **Developer**: 어떤 언어든 programming 경험이 필요합니다. Functional programming 개념에 익숙하면 도움이 되지만 필수는 아닙니다.
- **Operator**: Container 기반 배포(Docker, Kubernetes)와 기본 networking 개념에 관한 경험이 필요합니다.
- **모든 독자**: 사전 blockchain 경험은 필요하지 않습니다. 기초 원리부터 개념을 설명합니다.
