Integrations는 application을 Canton Network의 wallet, exchange, token 및 기타 service ecosystem과 연결합니다. Application developer가 기반으로 활용하고 end user가 직접 사용할 수 있는 즉시 사용 가능한 기능을 제공합니다.

## Integration 분류

Canton Network는 여러 종류의 integration을 제공합니다.

- **Wallets**: 사용자와 application을 위한 Canton Coin 관리
- **Exchange integration**: Liquidity bridge와 fiat on/off ramp
- **Token standards**: [CIP-0056](https://github.com/canton-foundation/cips/blob/main/cip-0056/cip-0056.md)을 따르는 interoperable token
- **Application integration**: Third-party app 연결

## Canton Integration과 다른 Ecosystem의 차이

Canton의 privacy model 때문에 integration은 public blockchain과 다르게 동작합니다.

- **Balance는 private입니다**: Wallet은 public이 아닌 권한 있는 Party에게만 holding을 표시합니다.
- **Transaction은 private입니다**: Transfer는 block explorer 전체가 아니라 participant에게만 표시됩니다.
- **Token은 private입니다**: Token balance는 holder에게만 표시됩니다.
- **Explorer는 개인별 관점입니다**: Canton explorer는 network 전체 활동이 아니라 사용자의 transaction만 표시합니다.

<Note>
모든 transaction을 표시하는 Ethereum blockchain explorer와 달리 Canton explorer는 사용자가 stakeholder인 transaction만 표시합니다. 이는 의도된 설계입니다.
</Note>
