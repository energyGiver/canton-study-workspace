User API는 User UI의 기반이 되는 JSON-RPC 2.0 API입니다. 사람이 UI에서 수행할 수 있는 session, network, Identity Provider, wallet 및 transaction 관리 작업을 같은 API로 programmatic하게 수행할 수 있습니다. Wallet 설정을 scripting하거나 app에 포함된 custom wallet UI를 구축하거나 backend operation을 자동화할 때 사용합니다.

이 guide에서는 일반적인 automation flow를 설명합니다. 전체 method 목록, authentication rule 및 OpenRPC specification은 [User API reference](/integrations/wallet-gateway/reference/user-api)를 참조하세요.

<Note>
User API는 **자신의** wallet과 setup을 제어합니다. dApp이 dApp SDK를 통해 user wallet에 연결할 때 호출하는 [dApp API](/integrations/wallet-gateway/reference/dapp-api)와는 다릅니다.
</Note>

## 시작하기 전 준비 사항

다음 항목이 필요합니다.

- 접근 가능한 실행 중인 Wallet Gateway, 예: `http://localhost:3030`. [Quickstart](/integrations/wallet-gateway/quickstart)를 참조하세요.
- 하나 이상의 설정된 network와 Identity Provider. [Networks & Identity Providers](/integrations/wallet-gateway/operate/networks-and-identity)를 참조하세요.
- 자동화 대상 user에 대해 해당 Identity Provider에서 JWT를 발급받을 방법

모든 호출은 User API base path에 보내는 JSON-RPC 2.0 `POST` request입니다. Default는 `/api/v0/user`이며 `server.userPath`로 설정할 수 있습니다.

```bash
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <jwt-token>' \
  -d '{ "jsonrpc": "2.0", "id": 1, "method": "<method>", "params": { } }'
```

대부분의 method에는 `Authorization` header가 필요합니다. Client가 connection을 bootstrap할 수 있도록 `addSession()`, `listNetworks()`, `listIdps()`는 이 header 없이 사용할 수 있습니다.

<Note>
Parameter 구조는 method마다 다릅니다. 정확한 request와 response field는 [OpenRPC specification](https://github.com/canton-network/wallet/blob/main/api-specs/openrpc-user-api.json)을 source of truth로 사용하세요.
</Note>

## Session 생성

Authentication이 필요 없는 `addSession()`으로 connection을 시작한 뒤 Identity Provider의 auth flow를 완료하여 JWT를 발급받습니다. 이후 모든 호출의 `Authorization` header에 이 JWT를 전달합니다.

```bash
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -d '{ "jsonrpc": "2.0", "id": 1, "method": "addSession", "params": { } }'
```

Wallet Gateway는 authenticate된 user에 연결된 session을 발급합니다. `listSessions()`로 active session을 조회하고 `removeSession()`으로 현재 session을 종료합니다.

## Network와 Identity Provider 탐색

Wallet을 생성하기 전에 Wallet Gateway가 제공하는 항목을 조회합니다. 두 호출 모두 authentication 없이 사용할 수 있습니다.

```bash
# List configured networks
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -d '{ "jsonrpc": "2.0", "id": 2, "method": "listNetworks", "params": { } }'

# List identity providers
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -d '{ "jsonrpc": "2.0", "id": 3, "method": "listIdps", "params": { } }'
```

Admin은 runtime에 `addNetwork()`, `removeNetwork()`, `addIdp()`, `removeIdp()`로 이 항목을 관리할 수도 있습니다. `server.admin`으로 설정된 user에게 admin privilege가 부여됩니다. [Wallet Gateway 설정](/integrations/wallet-gateway/operate/configure#server)을 참조하세요.

## Wallet 생성 및 관리

Network와 signing provider를 선택하여 wallet을 생성한 뒤 wallet method로 해당 집합을 관리합니다.

```bash
# Create a wallet (party) on a network
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <jwt-token>' \
  -d '{ "jsonrpc": "2.0", "id": 4, "method": "createWallet", "params": { } }'
```

| Method | Description |
| --- | --- |
| `createWallet()` | Network에 새 wallet, 즉 Party 생성 |
| `listWallets()` | 현재 user의 모든 wallet 조회 |
| `setPrimaryWallet()` | dApp이 default로 사용하는 primary wallet 설정 |
| `removeWallet()` | Wallet Gateway에서 wallet 제거 |
| `syncWallets()` | Wallet을 ledger와 synchronize |
| `isWalletSyncNeeded()` | Wallet synchronization 필요 여부 확인 |

## Transaction Sign 및 Execute

Wallet이 존재하면 `sign()`과 `execute()`로 transaction을 sign하고 submit한 뒤 transaction method로 status를 확인합니다.

```bash
# Sign a prepared transaction
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <jwt-token>' \
  -d '{ "jsonrpc": "2.0", "id": 5, "method": "sign", "params": { } }'

# Execute a signed transaction
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <jwt-token>' \
  -d '{ "jsonrpc": "2.0", "id": 6, "method": "execute", "params": { } }'
```

`getTransaction()`과 `listTransactions()`로 transaction을 조회합니다. Signing은 wallet의 [signing provider](/integrations/wallet-gateway/operate/signing-providers)에 위임되므로 key가 해당 provider를 벗어나지 않습니다.

## Real-Time Transaction 추적

dApp API는 real-time update를 위한 `txChanged`, `accountsChanged`, `connected`, `statusChanged` Server-Sent Event를 제공합니다. Custom UI를 구축한다면 polling 대신 이를 subscribe하세요. [Real-time events](/integrations/wallet-gateway/reference/dapp-api#real-time-events-sse)를 참조하세요.

## Session 종료

작업이 끝나면 session을 종료합니다.

```bash
curl -X POST http://localhost:3030/api/v0/user \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <jwt-token>' \
  -d '{ "jsonrpc": "2.0", "id": 7, "method": "removeSession", "params": { } }'
```
