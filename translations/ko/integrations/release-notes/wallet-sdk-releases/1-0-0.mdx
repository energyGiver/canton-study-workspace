# 1.0.0

**2026년 4월 17일 release**

Wallet SDK v1은 application development를 위한 새로운 장기 API model입니다.
v0에 additive patch를 적용한 것이 아니라 composability, multi-party flow, transport flexibility에 초점을 둔 더 명확하고 explicit한 model을 도입합니다.

**v1으로 이동해야 하는 이유**

- 기본적으로 stateless하고 더 안전함: v1은 global SDK/controller Party state를 제거하고 call 시점에 explicit `partyId`를 요구합니다. 이를 통해 thread safety를 개선하고 concurrent multi-party operation을 훨씬 쉽게 추론할 수 있습니다.
- 더 명확한 Transaction lifecycle: Flow를 explicit `prepare -> sign -> execute` 단계로 model하여 observability를 개선하고 hidden behavior를 줄입니다.
- 더 나은 API organization: v0 controller를 경계가 더 명확하고 찾기 쉬운 namespace(`ledger`, `party`, `token`, `amulet`, `user`, `asset`, `events`)로 대체합니다.
- 더 유연한 integration model: v1은 static configuration과 provider-based initialization을 지원하여 browser, dApp, remote wallet, alternative transport setup과 더 쉽게 통합할 수 있습니다.
- 개선된 extension model: Optional functionality를 `extend()`로 enable할 수 있어 base initialization을 작고 목적 지향적으로 유지합니다.

이 release note는 모든 method-level change를 의도적으로 나열하지 않습니다.
