# 0.9.0

**2025년 9월 26일 release**

- Canton 3.3과 3.4 동시 지원

*Canton 3.4가 곧 Splice에 도입되므로 사전에 두 version을 모두 지원할 수 있어야 합니다.*

- `localNetStaticConfig` 추가

*LocalNet에서 wallet API와 registry는 static이므로 초기 development를 더 쉽게 하기 위한 새 config가 추가되었습니다.*

```javascript
import {
    WalletSDKImpl,
    localNetAuthDefault,
    localNetLedgerDefault,
    localNetTopologyDefault,
    localNetTokenStandardDefault,
    localNetStaticConfig,
} from '@canton-network/wallet-sdk'

const sdk = new WalletSDKImpl().configure({
    logger,
    authFactory: localNetAuthDefault,
    ledgerFactory: localNetLedgerDefault,
    topologyFactory: localNetTopologyDefault,
    tokenStandardFactory: localNetTokenStandardDefault,
})

await sdk.connectTopology(localNetStaticConfig.LOCALNET_APP_VALIDATOR_URL)

sdk.tokenStandard?.setTransferFactoryRegistryUrl(
    localNetStaticConfig.LOCALNET_REGISTRY_API_URL
)
```
