# 0.19.0

**2025년 12월 29일 release**

- **중요: LedgerController constructor가 named parameter 방식으로 변경됨**

*`LedgerController` constructor가 positional parameter에서 named parameter object로 refactor됐습니다. `LedgerController`를 직접 construct하면 breaking change입니다. 새 signature는 wallet gateway 같은 intermediary를 통해 request를 routing할 때 유용한 optional custom `fetch` implementation도 받습니다.*

```javascript
// previous constructor
const ledger = new LedgerController(
    userId,
    new URL('http://127.0.0.1:5001'),
    token
)

// new constructor with named params
const ledger = new LedgerController({
    userId,
    baseUrl: new URL('http://127.0.0.1:5001'),
    token,
    // optional: provide a custom fetch to route requests through a proxy
    fetch: myCustomFetch,
})
```

- Update ID로 생성된 Contract 조회

*Ledger controller에 새 `getCreatedContractByUpdateId` method가 추가됐습니다. Transaction을 submit한 뒤 반환된 `updateId`를 사용해 해당 Transaction에서 생성된 Contract를 lookup할 수 있습니다. Template 또는 Interface ID를 제공해 result를 좁힐 수도 있습니다.*

```javascript
const result = await sdk.userLedger?.prepareSignExecuteAndWaitFor(
    transferCommand,
    keyPairSender.privateKey,
    v4(),
    disclosedContracts
)

const transferCid = (
    await sdk.userLedger!.getCreatedContractByUpdateId(
        result!.updateId,
        {
            interfaceIds: [TRANSFER_INSTRUCTION_INTERFACE_ID],
        }
    )
).contractId!
```

- 통합 `createTransferInstruction` choice helper

*Transfer Instruction의 Accept, Reject, Withdraw logic을 하나의 `createTransferInstruction` method로 통합해 어떤 특정 choice인지 신경 쓰지 않고 choice를 exercise할 때 boilerplate를 줄입니다.*

```javascript
const [command, disclosedContracts] =
    await sdk.tokenStandard!.createTransferInstruction(
        transferCid,
        'Accept' // or 'Reject' or 'Withdraw'
    )

await sdk.userLedger?.prepareSignExecuteAndWaitFor(
    command,
    keyPairSender.privateKey,
    v4(),
    disclosedContracts
)
```

- Ledger client의 browser 지원

*이제 browser environment에서 `@canton-network/core-ledger-client` package를 직접 import하고 사용할 수 있습니다. Main bundle에서 Node.js 전용 module을 제거해 browser 기반 dApp과 portfolio UI가 추가 bundler workaround 없이 Ledger utility를 활용할 수 있습니다.*

- Decimal precision 처리 수정

*크거나 fractional한 CC amount를 다룰 때 floating-point precision error를 방지하도록 `decimal.js`로 decimal arithmetic을 처리합니다.*
