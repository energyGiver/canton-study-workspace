# 0.18.0

**2025년 11월 26일 release**

- UTXO merge Command

*이제 `mergeHoldingUtxos` method를 호출해 UTXO merge를 쉽게 수행할 수 있습니다. 이 method는 asset을 merge하기 위해 개별 실행해야 하는 일련의 Command를 반환합니다. UTXO Command 목록을 반환하는 이유는 multi-asset을 지원해 CC와 non-CC Token을 모두 merge하고, Transaction당 input 상한이 100개이므로 그보다 많을 때 client를 위해 분할하기 때문입니다.*

```javascript
const [mergeUtxoCommands, mergedDisclosedContracts] =
    await sdk.tokenStandard!.mergeHoldingUtxos()!

for (let i = 0; i < mergeUtxoCommands.length; i++) {
    await sdk.userLedger?.prepareSignExecuteAndWaitFor(
        mergeUtxoCommands[i],
        keyPairSender.privateKey,
        v4(),
        mergedDisclosedContracts
    )
}
```

- UTXO merge delegation

*수동으로 monitor하고 동작하는 대신 [merge-delegation](https://docs.dev.sync.global/app_dev/token_standard/index.html#setting-up-mergedelegations)에 설명된 UTXO merge delegation을 새 기능으로 setup할 수 있습니다. 전체 setup example은 [Wallet SDK example 18](https://github.com/canton-network/wallet/blob/main/docs/wallet-integration-guide/examples/scripts/18-merge-delegation-proposal.ts)에서 확인할 수 있습니다.*

- Preapproval과 함께 Party 생성

*Preapproval과 함께 Party를 생성하는 것은 일반적인 task이므로 다른 여러 case처럼 combined function을 추가했습니다.*

```javascript
const receiver =
    await sdk.userLedger?.signAndAllocateExternalPartyWithPreapproval(
        keyPairReceiver.privateKey,
        validatorOperatorParty,
        instrumentAdminPartyId,
        'bob'
    )
```

- Traffic status 조회

*이전 release에서는 External Party를 사용한 Traffic purchase를 enable했습니다. 이제 balance를 fetch하는 option이 포함되어 External Party로 top up이 실제 필요한지 확인할 수 있습니다. 단, Token Standard Controller에 `scanApiBaseUrl`을 제공해야 합니다.*

```javascript
const trafficStatus =
    await sdk.tokenStandard!.getMemberTrafficStatus(participantId!)
```

- Offset에서 Holding 목록 조회

*`listHoldingsUtxo`에 optional offset parameter가 추가됐습니다. 보통 Ledger End를 사용하지만 이제 직접 정의할 수 있습니다. 이 operation은 performance가 좋지 않다는 점에 유의하세요.*
