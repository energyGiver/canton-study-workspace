# 1.2.0

**2026년 5월 13일 release**

- No-auth Validator/Ledger configuration 연결 허용

*Initialization flow가 `/v2/authenticated-user`를 사용할 수 없는 setup을 처리하고, 가능한 경우 auth context에서 `userId`를 derive할 수 있습니다. 이를 통해 no-auth 및 transitional environment에서 더 원활하게 연결할 수 있습니다.*

- Auth context가 없을 때 더 명확한 error behavior

*SDK initialization 중 error handling을 개선하여 authentication context 누락 문제를 더 쉽게 진단하고 해결할 수 있습니다.*

- Stress 상황의 merge UTXO precision 개선

*누적 merge amount가 예상 decimal precision 안에 유지되도록 merge UTXO logic을 update하여 heavy/batch merge scenario의 reliability를 개선했습니다.*
