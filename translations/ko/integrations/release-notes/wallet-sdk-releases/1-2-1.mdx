# 1.2.1

**2026년 5월 13일 release**

- Wallet SDK type inference 수정

*Optional `extend` option과 SDK initialization 주변의 typing issue를 수정하여 TypeScript inference를 개선하고 consumer project의 false-positive type error를 줄였습니다.*

- 알 수 없는 Canton version과의 compatibility 개선

*새롭거나 알 수 없는 Canton version이 감지되면 SDK stack이 즉시 실패하는 대신 warning을 표시하고 compatible client version으로 fallback합니다. Warning을 알리면서도 forward compatibility를 더 원활하게 제공합니다.*

- Unauthenticated connection error handling 강화

*Unauthenticated connection detection의 사소한 exception handling edge case를 수정하여 오해를 부르는 failure를 방지했습니다.*
