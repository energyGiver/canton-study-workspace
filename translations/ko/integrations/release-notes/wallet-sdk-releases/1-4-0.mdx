# 1.4.0

**2026년 7월 8일 release**

- Token 및 Amulet namespace의 optional `validatorUrl`

*이제 Wallet SDK의 Token 및 Amulet namespace를 `validatorUrl` 없이 initialize할 수 있습니다.
Amulet 및 Token 전용 operation에는 Ledger API와 Registry URL만 expose하면 됩니다.
`validatorApi`를 이 namespace에 expose하려는 사용자는 optional parameter인 `validatorUrl`을 계속 제공할 수 있습니다.*

```javascript
import { SDK } from '@canton-network/wallet-sdk'

const sdk = await SDK.create({
    auth: {
        method: 'self_signed',
        issuer: 'unsafe-auth',
        credentials: {
            clientId: 'ledger-api-user',
            clientSecret: 'unsafe',
            audience: 'https://canton.network.global',
            scope: '',
        },
    },
    ledgerClientUrl: localNetStaticConfig.LOCALNET_APP_USER_LEDGER_URL,
    token: {
        registries: [
            new URL('http://localhost:2000/api/validator/v0/scan-proxy'),
        ],
        auth: {
        method: 'self_signed',
        issuer: 'unsafe-auth',
        credentials: {
            clientId: 'ledger-api-user',
            clientSecret: 'unsafe',
            audience: 'https://canton.network.global',
            scope: '',
        },
    },
    },
    amulet: {
        scanApiUrl: 'http://scanapi:8080',
        auth: {
        method: 'self_signed',
        issuer: 'unsafe-auth',
        credentials: {
            clientId: 'ledger-api-user',
            clientSecret: 'unsafe',
            audience: 'https://canton.network.global',
            scope: '',
        },
    },
        registryUrl: 'http://registry:8080',
    },
})
```

- Validator Party를 조회하는 function

*Validator operator Party가 필요한 특정 function을 위해 Validator URL로 Party를 조회하는 method를 제공합니다.*

```javascript
import { getValidatorParty } from '@canton-network/wallet-sdk'

const validatorParty = await getValidatorParty(
    new URL('http://validatorurl'),
    {
    method: 'self_signed',
    issuer: 'unsafe-auth',
    credentials: {
        clientId: 'ledger-api-user',
        clientSecret: 'unsafe',
        audience: 'https://canton.network.global',
        scope: '',
    }
)
```

- Custom logger type export

*`@canton-network/wallet-sdk`에서 `CustomLogAdapter`와 logger adapter type을 export합니다. 따라서 SDK 사용자는 internal path에서 import하지 않고 자체 logging implementation을 제공할 수 있습니다.*

- Bug fix: Transfer 생성 시 instrument 기준으로 Holding filter

*`sdk.token.transfer.create`에 `instrumentId`와 `instrumentAdmin`을 전달하면 SDK는 transfer를 생성하기 전에 instrument 기준으로 Holding을 filter합니다.
이전에는 Party의 Holding에 둘 이상의 instrument가 있으면 workaround로 `inputUtxos`를 전달해야 했습니다.*
