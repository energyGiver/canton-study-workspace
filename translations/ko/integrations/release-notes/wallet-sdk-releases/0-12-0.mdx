# 0.12.0

**2025년 10월 15일 release**

- **중요: create transfer의 custom metadata format이 변경되었습니다**

```javascript
//previous format
await sdk.tokenStandard!.createTransfer(
        sender!.partyId,
        receiver!.partyId,
        '100',
        {
            instrumentId: 'Amulet',
            instrumentAdmin: instrumentAdminPartyId,
        },
        [],
        'memo-ref',
        new Date(Date.now() + 24 * 60 * 60 * 1000),
        {
            key1: "value1",
            key2: "value2"
        }
    )

//new format
await sdk.tokenStandard!.createTransfer(
        sender!.partyId,
        receiver!.partyId,
        '100',
        {
            instrumentId: 'Amulet',
            instrumentAdmin: instrumentAdminPartyId,
        },
        [],
        'memo-ref',
        new Date(Date.now() + 24 * 60 * 60 * 1000),
            {
            values: {
                key1: "value1",
                key2: "value2"
            }
        }
    )
```

- featured app marker delegation proxy

*Wallet SDK는 External Party submission flow에 중점을 두지만 Validator Operator Party처럼 internally hosted된 Party를 사용해야 하는 administrative task도 있습니다. featured app marker에 필요한 delegation proxy contract를 설정할 때 특히 유용합니다.*

```javascript
const delegateCommand = await sdk.userLedger?.createDelegateProxyCommand(
    exchangeParty,
    treasuryParty
)

const delegationContractResult =  await sdk.userLedger?.submitCommand(delegateCommand)
```

- offline Command 생성 가능

*transfer 같은 일부 Command는 transferInstruction choice context 같은 관련 data를 fetch해야 하므로 online context에서 수행해야 했습니다. 이제 미리 fetch하는 방식을 선호할 경우 사용할 수 있도록 이 method와 allocation에 optional parameter가 추가되었습니다.*

```javascript
const choiceContext = await sdk.tokenStandard?.getCreateTransferContext(
    senderParty,
    receiverParty,
    amount,
    { instrumentId, instrumentAdmin},
    //normal optional parameters for a transfer here like memo and utxos
    )

 //OFFLINE

 const transferCommand = await sdk.tokenStandard?.createTransfer(
    senderParty,
    receiverParty,
    amount,
    { instrumentId, instrumentAdmin},
    prefetchedRegistryChoiceContext: choiceContext
 )
```

- Party 생성 stress test

*MainNet에서는 Party 생성에 load가 많이 걸려 `The server was not able to produce a timely response to your request`가 지속적으로 발생했습니다. 이에 대한 safeguard가 추가되어 error 발생 시 Party를 사용할 수 있을 때까지 계속 찾습니다. timeout이 필요하다면 method 밖에서 처리해야 합니다. ledger의 Party 생성에는 timeout이 없다는 점에 유의할 가치가 있습니다.*

`expectHeavyLoad`를 false로 설정하면 비활성화할 수 있습니다.

```javascript
 /** Submits a prepared and signed external party topology to the ledger.
 * This will also authorize the new party to the participant and grant the user rights to the party.
 * @param signedHash The signed combined hash of the prepared transactions.
 * @param preparedParty The prepared party object from prepareExternalPartyTopology.
 * @param grantUserRights Defines if the transaction should also grant user right to current user (default is true)
 * @param expectHeavyLoad If true, the method will handle potential timeouts from the ledger api (default is true).
 * @returns An AllocatedParty object containing the partyId of the new party.
 */

async allocateExternalParty(
    signedHash: string,
    preparedParty: GenerateTransactionResponse,
    grantUserRights: boolean = true,
    expectHeavyLoad: boolean = true
)
```
