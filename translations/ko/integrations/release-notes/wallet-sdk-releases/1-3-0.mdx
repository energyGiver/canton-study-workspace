# 1.3.0

**2026년 5월 20일 release**

- Wallet SDK v1의 plugin registration 지원

*이제 `registerPlugins`와 `SDKPlugin`을 사용해 custom plugin으로 Wallet SDK를 확장할 수 있습니다. SDK context, logger, namespace function에 대한 typed access를 유지하면서 project-specific method를 더 쉽게 추가할 수 있습니다.*

```javascript
import { SDK, SDKContext, SDKPlugin } from '@canton-network/wallet-sdk'

const sdk = (await SDK.create({
    auth: {
        method: 'self_signed',
        issuer: 'unsafe-auth',
        credentials: {
            clientId: 'ledger-api-user',
            clientSecret: 'unsafe',
            audience: 'https://canton.network.global',
            scope: '',
        },
    },
    ledgerClientUrl: 'http://localhost:2975',
})).registerPlugins({
    myPlugin: class extends SDKPlugin {
        constructor(protected readonly ctx: SDKContext) {
            super('myPlugin', ctx)
        }
    },
})
```

- v1 Token namespace에서 update ID로 Transaction fetch

*`sdk.token`에 전용 `transactionsById` method가 추가되어 `updateId`와 `partyId` pair로 parsing된 token-standard Transaction detail을 조회할 수 있습니다. 이는 completion/update ID에서 추적하는 일반적인 post-submission lookup flow에 맞습니다.*

```javascript
const transaction = await sdk.token.transactionsById({
    updateId: completion.updateId,
    partyId: sender.partyId,
})
```

- Quick preapproval fetch 지원

*Amulet preapproval namespace에는 Scan Proxy에 대해 retry 없이 한 번 lookup하는 `fetchQuick`이 포함됩니다. `fetchStatus`의 polling이나 wait semantics 없이 빠르게 current state를 확인할 때 유용합니다.*

```javascript
const preapproval = await sdk.amulet.preapproval.fetchQuick(receiver.partyId)
```
