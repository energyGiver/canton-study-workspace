이 guide는 Mario Delgado 팀이 blockchain onboarding에 사용하는 `x-docker` standard를 따르는, Canton Validator Node 및 지원 infrastructure deployment용 community 제공 Docker Compose solution을 소개합니다. DevNet의 scheduled upgrade 중 test했지만 `.env` file의 migration ID update, database rename(`participant_${MIGRATION_ID}` 및 `validator_${MIGRATION_ID}` 같은 standardized name을 사용하도록 변경 예정), migration setup에 `validator-migration.yaml` 포함이 필요했다는 점에 유의하세요. 자세한 내용은 contribution author에게 문의하세요. 이 solution은 extensibility, operational flexibility 및 더 넓은 infrastructure와의 integration을 강조합니다. 공식 지원 Docker Compose deployment는 [Validator Node의 Docker Compose 기반 Deployment](/global-synchronizer/deployment/validator-docker-compose)를 참조하세요.

Community discussion에서 이 solution을 공유한 Mario Delgado에게 감사드립니다. 자세한 내용과 향후 update는 [CryptoManufaktur-io/canton-docker](https://github.com/CryptoManufaktur-io/canton-docker) repository를 참조하세요.

## Solution의 주요 Feature

- `x-docker` standard에 맞춘 Canton용 custom Docker Compose setup
- Upgrade를 위한 `validator-migration.yaml` 기반 Validator migration 지원
- Setup 및 maintenance용 자동 installation/update script
- Custom override(`custom.yml`)와 environment variable 지원으로 base file 수정 없이 advanced configuration 가능
- `central-proxy-docker` 및 `:ext-network.yml`을 통한 Traefik(proxy)과 Prometheus(monitoring) integration guide
- Kubernetes environment용 experimental Helm chart(2025년 6월 기준 개발 중)
- Disaster recovery feature(2025년 6월 기준 개발 중)
