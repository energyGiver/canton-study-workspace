## Ingress

Validator에는 external ingress requirement가 없으며 다른 SV 또는 Validator를 whitelist할 필요가 없습니다.

## Egress

Validator는 모든 SV에 연결할 수 있어야 하므로 모든 SV IP에 대해 port 443 egress를 whitelist해야 합니다. Network 개요는 [Network diagram](/global-synchronizer/deployment/validator-kubernetes)을 참조하세요. Egress는 대개 default로 허용되므로 많은 경우 별도 action이 필요하지 않습니다.
