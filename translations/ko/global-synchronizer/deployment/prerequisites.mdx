이 section에서는 Validator 실행을 위한 hardware requirement를 설명합니다. 이 값은 reference value이며 실제 requirement는 Validator usage에 따라 달라질 수 있습니다. Production Validator Node의 모든 component에 대한 CPU 및 memory usage와 database disk usage를 monitor하고 필요에 따라 resource를 조정하는 것이 좋습니다.

Requirement에는 Validator 및 Participant container가 모두 포함됩니다.

이 requirement는 Docker Compose 기반 deployment와 Kubernetes deployment에서 대체로 동일하지만 Kubernetes 자체 또는 ingress의 overhead는 제외합니다.

| Usage                                                           | CPU | Memory | DB CPU | DB Memory | DB size |
|-----------------------------------------------------------------|-----|--------|--------|-----------|---------|
| Local laptop 또는 최소 VM에서 experiment                       | 1   | 6GB    | 1      | 1GB       | 1GB     |
| Activity가 적은 production Validator                            | 2   | 8GB    | 2      | 4GB       | 10GB    |
| Activity가 보통인 app provider용 production Validator           | 2   | 16GB   | 2      | 4GB       | 100GB   |

## Database Latency

Component는 database latency에 비교적 민감합니다. GCP CloudSQL과 같은 managed database offering을 사용하는 경우 cluster가 실행되는 것과 동일한 region 및 zone에 allocate하는 것이 좋습니다.
