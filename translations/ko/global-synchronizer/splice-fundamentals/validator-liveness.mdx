각 round에서 active한 각 Validator는 [ValidatorLivenessActivityRecord](/sdks-tools/api-reference/splice-daml/splice-amulet/splice-validatorlicense#type-splice-validatorlicense-validatorlivenessactivityrecord-17293)를 사용하여 liveness activity를 기록합니다.

[CIP-0096](https://github.com/canton-foundation/cips/blob/main/cip-0096/cip-0096.md)은 Validator liveness reward를 중단했으며, Validator별 liveness reward cap을 단계적으로 낮춰 2026-04-30부터 $0으로 만들었습니다. 이제 Validator는 activity reward를 통해서만 CC를 얻습니다. 현재 Validator가 CC를 얻는 방식은 [Canton Coin과 Global Synchronizer](/overview/understand/canton-coin)를 참조하세요.
