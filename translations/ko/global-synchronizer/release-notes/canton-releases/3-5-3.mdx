# Canton 3.5.3 Release

Canton 3.5.3은 2026년 6월 3일에 release되었습니다.

## Summary

Mediator restart 및 LSU 관련 issue를 수정하는 maintenance release입니다.

## Bugfix

### LSU sequencing test message 처리 후 Mediator가 Sequencer에 다시 연결할 수 없음

LSU 중 sequencing test message를 처리한 후 Mediator가 Sequencer에 다시 연결할 수 없습니다.
Upgrade time에 도달하고 Sequencer에서 traffic이 initialize되면 connection issue가 저절로 해결됩니다.

## Compatibility

다음 Canton protocol version이 지원됩니다.

| Dependency                 | Version                    |
|----------------------------|----------------------------|
| Canton protocol version    | 34, 35          |

Canton은 다음 dependency version을 대상으로 test되었습니다.

| Dependency                 | Version                    |
|----------------------------|----------------------------|
| Java Runtime               | OpenJDK 64-Bit Server VM (build 21.0.12+2-nixos, mixed mode, sharing)               |
| Postgres                   | 권장: PostgreSQL 17.10 (Debian 17.10-1.pgdg13+1) – 추가 test: PostgreSQL 14.23 (Debian 14.23-1.pgdg13+1), PostgreSQL 15.18 (Debian 15.18-1.pgdg13+1), PostgreSQL 16.14 (Debian 16.14-1.pgdg13+1)           |
