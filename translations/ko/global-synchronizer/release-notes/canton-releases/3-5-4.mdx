# Canton 3.5.4 Release

Canton 3.5.4는 2026년 6월 10일에 release되었습니다.

## Summary

Synchronizer 수정 관련 bug를 해결하고 몇 가지 improvement를 제공하는 maintenance release입니다.

## 새로운 기능

### Minor Improvement
- Config flag `canton.participants.participant.parameter.alpha-multi-synchronizer-support`의 name이 `enable-all-ledger-api-reassignments`로 변경되었습니다.
- Participant Topology feature flag `EnableAlphaMultiSynchronizer`의 name이 `EnableMultiSynchronizer`로 변경되었습니다.
- ACS commitment processor와 store 사이의 coordination을 개선하여 Participant shutdown 중 benign `DB_STORAGE_DEGRADATION` warning이 발생하지 않도록 했습니다.

#### Synchronizer 목록 조회 관련 improvement

- Message `ListRegisteredSynchronizersRequest`에 새 `all_statuses` attribute가 추가되어 active 상태인 Synchronizer뿐 아니라 등록된 모든 Synchronizer를 retrieve할 수 있습니다.
- 등록된 모든 Synchronizer를 나열하는 새 Console Command `participant1.synchronizers.list_all_registered`가 추가되었습니다.

#### BFT Orderer database pruning 및 performance 관련 improvement

- BFT Orderer database table에 database table partitioning이 도입되었습니다.
- 이러한 변경으로 pruning operation 및 optimize된 여러 다른 query의 performance가 크게 개선됩니다.
- 중요: 이러한 변경에는 새 automatic database migration 실행이 필요하며, migration 시점에 영향받는 table에 있는 data 양에 따라 상당한 시간이 걸릴 수 있습니다.

## Bugfix

- Physical Synchronizer ID가 설정된 경우 `ModifySynchronizer` request가 실패하던 issue를 수정했습니다.
