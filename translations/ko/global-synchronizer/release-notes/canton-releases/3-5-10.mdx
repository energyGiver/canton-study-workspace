# Canton 3.5.10 Release

Canton 3.5.10은 2026년 7월 23일에 release되었습니다.

## Summary

UX 및 hardening 개선을 제공하는 maintenance release입니다.

## 새로운 기능

### Minor Improvement
- Proto duration deserialization이 실패할 수 있는 edge case를 수정했습니다.
- Max serial이 있는 Topology Transaction을 올바르게 처리하지 못하던 issue를 수정했습니다.
- 이제 Ledger JSON API `/v2/state/active-contracts-page`를 POST로 사용할 수 있습니다. Request body를 요구하는 GET variant는 deprecated되었습니다.
- Postgres 18 지원을 활성화하기 위해 Flyway dependency를 12.0.2로 올렸습니다.

## Compatibility

다음 Canton protocol version이 지원됩니다.

| Dependency                 | Version                    |
|----------------------------|----------------------------|
| Canton protocol version    | 34, 35          |
