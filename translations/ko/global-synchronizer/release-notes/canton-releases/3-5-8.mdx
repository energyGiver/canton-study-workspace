# Canton 3.5.8 Release

Canton 3.5.8은 2026년 7월 9일에 release되었습니다.

## Summary

여러 operational improvement를 제공하는 maintenance release입니다.

## 새로운 기능

#### `TopologyManagerReadService` 및 `TopologyAggregationService` improvement
- Topology store가 아직 initialize되지 않은 경우 service가 `TOPOLOGY_STORE_NOT_INITIALIZED` error를 반환합니다.
  이는 다음 두 경우에 발생할 수 있습니다.
  - Synchronizer onboarding 중 initial Topology state download 및 processing이 완료되기 전
  - Logical Synchronizer upgrade 중 local Topology copy 또는 successor Sequencer의 Topology state download를 통해 successor store가 initialize되기 전
- Node가 알지 못하는 Synchronizer의 Topology data를 요청하면 service가 `TOPOLOGY_STORE_NOT_FOUND` error를 반환합니다.
- 이제 request에 Synchronizer가 지정되지 않은 경우 service는 모든 active Synchronizer의 data만 반환합니다.
  이전에는 LSU 후 inactive predecessor Synchronizer를 포함하여 모든 Synchronizer의 data가 반환되었습니다.

#### Database connection error reporting improvement
Database call이 구성된 `postgres_data_source.network_timeout`보다 오래 걸리면 더 구체적인 새 `INDEX_DB_SQL_NETWORK_TIMEOUT_ERROR`가 log에 기록됩니다. 이는 이전에 발생하던 `INDEX_DB_SQL_NON_TRANSIENT_ERROR`를 대체합니다.

### Minor Improvement
- JSON Ledger API의 log trace correlation을 개선했습니다. 이전에 빈 trace context로 log를 남기던 package 및 health endpoint가 이제 caller의 `TraceContext`를 propagate합니다.
- JSON Ledger API endpoint `GET /v2/interactive-submission/preferred-package-version`이 OpenAPI specification에서도 deprecated로 표시됩니다. 이전에는 textual description에서만 deprecated로 표시되었습니다. 대신 `POST /v2/interactive-submission/preferred-packages`를 사용하세요. Endpoint는 계속 작동하지만 Canton 3.6에서 제거될 예정입니다.
