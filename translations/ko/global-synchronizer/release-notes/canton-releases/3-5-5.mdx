# Canton 3.5.5 Release

Canton 3.5.5는 2026년 6월 17일에 release되었습니다.

## Summary

Logical Synchronizer upgrade와 관련된 드물지만 심각한 bug를 수정하고 몇 가지 improvement를 제공하는 maintenance release입니다.

## 새로운 기능

### Vetted package의 dependency를 unvet 가능(PV35 이상)
Protocol version 35 이상을 실행하는 Synchronizer에서는 API의 vetting state 변경 operation(예: ``/package-vetting/update``)을 통해 force flag를 사용하지 않고도 vetted package의 dependency를 안전하게 unvet할 수 있습니다.
이는 PV35 이상에서 Daml Transaction Node package의 dependency가 vet 상태일 것을 요구하지 않는 Transaction protocol과 일치합니다.
**Note**: Protocol version 34 이하에서는 package dependency vetting restriction이 변경되지 않습니다.

### Minor Improvement

- Docker base image를 1.0.8에서 1.0.9로 update하여 grpc-health-probe를 v0.4.52로 올렸습니다.
- 전체 response buffering을 피하고 대형 gRPC response를 streaming하여 memory footprint를 줄였습니다.
- Closed subscription 때문에 event signal을 queue에 넣을 수 없는 경우 Sequencer log message를 개선하고 이를 error로 설명하지 않도록 했습니다.
- 새 Participant config `canton.participants.myParticipant.parameters.connect-to-synchronizers-on-startup`을 사용하여 startup 시 Synchronizer 자동 연결을 비활성화할 수 있습니다.

## Bugfix

### (26-003, High): Stuck Sequencer restart로 인한 Sequencer fork

#### Issue Description
LSU 전후에 block을 처리하지 않는 Sequencer가 upgrade time 이후이면서 아직 어떤 block도 처리하기 전에 restart되면 crash recovery의 일부로 traffic data entry를 삭제합니다.

#### Affected Deployment
Sequencer Node

#### Affected Version
3.5.5 이전의 모든 version

#### Impact
Sequencer fork

#### Symptom
Participant가 연결할 수 없거나(traffic에 대한 consensus를 얻지 못함) `SEQUENCER_FORK_DETECTED`로 disconnect됩니다.

#### Workaround
Backup에서 restore합니다.

#### Likeliness
드물게 발생

#### Recommendation
3.5.5로 upgrade하세요.
