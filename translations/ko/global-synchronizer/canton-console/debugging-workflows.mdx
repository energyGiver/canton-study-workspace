Transaction이 실패하거나 Node 연결이 끊기거나 system이 예상과 다르게 동작할 때 Canton Console은 문제를 diagnose하는 tool을 제공합니다. 이 페이지에서는 구체적인 Console Command를 사용하여 일반적인 debugging scenario를 단계별로 설명합니다.

## 멈춘 Transaction Debugging

Command를 제출했지만 completion event가 도착하지 않으면 Transaction이 "stuck" 상태로 보입니다. 일반적인 원인은 stakeholder의 Participant에 연결할 수 없거나, 필요한 package가 vetted 상태가 아니거나, Synchronizer가 Transaction을 거부한 경우입니다.

### 1단계: Node Health 확인


<CANTON_DOCS_CN_GS_CANTON_CONSOLE_DEBUGGING_WORKFLOWS_0 />


Participant가 active 상태가 아니거나 연결된 Synchronizer가 없으면 Transaction을 진행할 수 없습니다.

### 2단계: Synchronizer Connectivity 확인


<CANTON_DOCS_CN_GS_CANTON_CONSOLE_DEBUGGING_WORKFLOWS_1 />


Synchronizer 연결이 끊겼다면 Network connectivity를 확인하고 다시 연결해 보세요.


<CANTON_DOCS_CN_GS_CANTON_CONSOLE_DEBUGGING_WORKFLOWS_2 />


### 3단계: Package Vetting 확인

Stakeholder의 Participant가 필요한 package를 vet하지 않았다면 Transaction이 실패합니다.


<CANTON_DOCS_CN_GS_CANTON_CONSOLE_DEBUGGING_WORKFLOWS_3 />


Package가 vetted 상태가 아니면 upload하고 vet합니다.


<CANTON_DOCS_CN_GS_CANTON_CONSOLE_DEBUGGING_WORKFLOWS_4 />


### 4단계: Party Hosting 확인

Transaction에 참여하는 모든 Party가 올바르게 hosting되어 있는지 확인합니다.


<CANTON_DOCS_CN_GS_CANTON_CONSOLE_DEBUGGING_WORKFLOWS_5 />


Party가 active Participant에 mapping되어 있지 않으면 Synchronizer가 해당 Party의 stakeholder에게 Transaction view를 전달할 수 없습니다.

Party ID가 아무 결과도 반환하지 않는 경우:

## ACS 검사

Application 동작이 예상과 다르면 Active Contract Set을 검사하여 on-ledger state를 확인합니다.


<CANTON_DOCS_CN_GS_CANTON_CONSOLE_DEBUGGING_WORKFLOWS_9 />


### Participant 간 ACS 비교

두 Participant가 같은 Party에 대해 서로 다른 state를 본다면 특정 template의 ACS count를 비교합니다. 차이가 있으면 synchronization 문제를 나타냅니다. 두 Participant가 같은 Synchronizer에 연결되어 있고 같은 package를 vet했는지 확인하세요.

## Diagnostic Checklist

문제를 조사할 때 다음 순서로 진행합니다.

1. **Health** — Node가 실행 중입니까? `participant.health.status`
2. **Connectivity** — Synchronizer가 연결되어 있습니까? `participant.synchronizers.list_connected`
3. **Package** — 필요한 package가 upload되고 vetted 상태입니까? `participant.topology.vetted_packages.list()`
4. **Party** — Party가 올바르게 hosting되어 있습니까? `participant.parties.hosted()`
5. **Topology** — Party-to-Participant mapping이 올바릅니까? `participant.topology.party_to_participant_mappings.list(syncId)`
6. **ACS** — On-ledger state가 예상과 일치합니까? `participant.testing.acs_search(...)`
