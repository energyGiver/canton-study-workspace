이 reference는 가장 자주 사용하는 Canton Console Command를 task별로 정리합니다. 별도 설명이 없으면 모든 example은 Participant Console에 연결된 상태를 가정합니다.

Canton Console이 시작되면 configuration file을 읽고 구성된 각 Node에 대한 variable을 자동으로 binding합니다. 예를 들어 configuration에 Participant Node가 정의되어 있으면 Console은 해당 Node를 `participant` variable 또는 config에서 지정한 이름으로 제공합니다. 추가 setup 없이 이 variable을 직접 사용하여 `participant.health.status`와 같은 Command를 호출할 수 있습니다.
