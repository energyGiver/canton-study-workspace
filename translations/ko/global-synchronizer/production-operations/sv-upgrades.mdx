Upgrade에는 두 가지 유형이 있습니다.

Version upgrade(`0.A.X`에서 `0.B.Y`로 upgrade)와 protocol upgrade(actual version은 그대로이고 protocol만 upgrade)가 있습니다.

Version upgrade는 각 Node에서 독립적으로 수행할 수 있으며 `helm upgrade`만 필요합니다. Upgrade의 일부로 변경해야 할 사항을 확인하도록 `release_notes`를 반드시 읽으세요.

Protocol upgrade는 Logical Synchronizer upgrade를 통해 수행되며 Network downtime을 매우 제한하면서 protocol version을 upgrade할 수 있습니다.
