<Note>

</Note>

- Validator app
- Participant

Super Validator에서는 다음 component도 metric을 expose합니다.

## Metric scrape

OpenTelemetry를 사용해 metric을 생성하며, 이 metric은 Prometheus format으로 expose되어 Prometheus server에서 scrape할 수 있습니다. 기존 metric reference는 [metric reference](/global-synchronizer/reference/metrics-reference)를 확인하세요.

### Histogram

Histogram을 [exponential histogram](https://opentelemetry.io/docs/specs/otel/metrics/data-model/#exponentialhistogram)으로 expose하고 이를 [Prometheus native histogram](https://prometheus.io/docs/specs/native_histograms/)으로 변환합니다.

<Note>
`-enable-feature=native-histograms` flag를 사용하여 Prometheus support를 활성화해야 합니다.

Native histogram은 protobuf format에서만 사용할 수 있으므로 Prometheus가 protobuf collection format으로 전환합니다.
</Note>

Node에 다음 environment variable을 추가하여 regular histogram으로 다시 전환할 수 있습니다. `ADDITIONAL_CONFIG_DISABLE_NATIVE_HISTOGRAMS="canton.monitoring.metrics.histograms=\[\]"`

### Metric 활성화

#### Helm deployment에서 metric 활성화

Helm deployment에서 metric을 활성화하려면 Helm values의 `metrics.enable` 값을 `true`(default `false`)로 설정합니다. 그러면 `ServiceMonitor` Kubernetes custom resource가 생성됩니다. 이 기능을 사용하려면 cluster에 Prometheus operator가 설치되어 있어야 합니다.

또는 port 10013을 scrape하도록 구성된 Prometheus scrape annotation을 chart에 추가할 수 있습니다.

#### Docker Compose deployment에서 metric 활성화

<Note>
Validator Node에만 해당
</Note>

Docker Compose를 deployment에 사용하는 경우 metric은 default로 활성화됩니다. Validator app은 `http://validator.localhost/metrics`, Participant는 `http://participant.localhost/metrics`에서 metric에 접근할 수 있습니다.

#### 추가 metric trigger 활성화

Validator app은 Topology state를 poll하고 해당 state를 요약하는 metric을 export하는 trigger를 실행하도록 구성할 수 있습니다. 이 metric에는 `splice.synchronizer-topology` prefix가 있습니다. 구체적인 metric 집합은 [validator metric reference](/global-synchronizer/reference/metrics-reference)를 참조하세요.

이 trigger는 default로 비활성화되어 있습니다. [Ad-hoc configuration 추가](/global-synchronizer/deployment/configuration)의 내용에 따라 environment variable `ADDITIONAL_CONFIG_TOPOLOGY_METRICS_EXPORT=canton.validator-apps.validator_backend.automation.topology-metrics-polling-interval = 5m`을 추가하여 polling interval 5분으로 trigger를 활성화합니다.

## Grafana Dashboard

Release bundle에는 Grafana instance로 import할 수 있는 Grafana dashboard가 포함되어 있습니다. 이 dashboard는 Kubernetes deployment를 가정하며 Prometheus native histogram query를 사용합니다.

Dashboard folder 위치는 Splice version에 따라 달라집니다.

- Splice `0.6.4`까지는 `grafana-dashboards/` folder를 사용합니다.
- Splice `0.6.5`부터 Validator operator는 `validator-grafana-dashboards/`, Super Validator operator는 `sv-grafana-dashboards/`를 사용해야 합니다.
