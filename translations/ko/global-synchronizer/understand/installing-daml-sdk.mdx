이 Splice release를 build하는 데 사용된 것과 정확히 같은 Daml SDK version을 설치할 필요는 없습니다. 이 version들은 참고용으로만 제공됩니다. 이전 3.x Daml SDK로 build한 `.dar` file은 일반적으로 이 Splice release에서 사용하는 Canton version과 호환됩니다.

app과 Validator Node의 상호 작용을 test할 때는 이 Splice release에서 사용하는 Canton version을 권장합니다. Validator deployment 지침에 따라 Validator Node를 deploy하면 해당 version을 사용하게 됩니다.

Daml SDK의 최신 기능과 bug fix를 활용하려면 이 Splice release에서 사용하는 Canton version과 *major 및 minor version이 같은* 최신 Daml SDK release를 사용하는 것이 좋습니다.

호환되는 최신 OSS Daml SDK version을 설치하려면 다음 단계를 따르세요.

1.  위와 같은 major 및 minor version을 가진 가장 최신 stable release를 선택합니다.

2.  다음을 사용하여 해당 release를 설치합니다.
