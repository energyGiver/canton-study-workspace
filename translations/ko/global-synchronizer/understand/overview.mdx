## Canton Network

[Canton Network](https://www.canton.network)는 규제 대상 real-world asset을 위해 설계된 최초의 privacy-enabled interoperable blockchain network입니다. Canton Network의 blockchain application은 Global Synchronizer를 사용하여 privacy나 control을 포기하지 않고도 독립적인 blockchain 사이에서 atomic transaction을 수행할 수 있습니다.

- [Global Synchronizer](https://www.canton.network/global-synchronizer)는 Canton Network를 위한 decentralized interoperability service이며, 투명한 governance를 따릅니다.
- Canton Network의 native token인 Canton Coin은 Global Synchronizer의 일부로 출시된 utility token입니다. 다른 network의 enterprise 도입 장벽을 극복하고 규제 금융 기업이 사용하는 ecosystem과 호환되도록 설계되었습니다.

특정 mechanism에 관해 더 자세한 내용이 필요하면, 예를 들어 fee 계산, activity record 구조 또는 minting round에 관한 기술 사양은 다음 white paper를 참조하세요. [Canton Network white paper](https://www.digitalasset.com/hubfs/Canton/Canton%20Network%20-%20White%20Paper.pdf), [Canton Coin white paper](https://www.digitalasset.com/hubfs/Canton%20Network%20Files/Documents%20(whitepapers%2c%20etc...)/Canton%20Coin_%20A%20Canton-Network-native%20payment%20application.pdf).

## Global Synchronizer

Global Synchronizer는 decentralized 방식으로 운영되는 service입니다. Message ordering과 confirmation에는 2/3 다수의 Byzantine Fault Tolerant(`BFT`) consensus protocol을 사용하고, governance 변경에는 BFT 다수결 voting을 사용합니다.

Global Synchronizer infrastructure는 Super Validator라는 독립적인 조직들이 운영합니다. 이들은 decentralized infrastructure의 component를 실행하고 on-chain governance application을 통해 활동을 조정합니다. Open source code는 [Splice](https://github.com/canton-network/splice)에서 관리됩니다.

[Canton Foundation("CF")](https://sync.global)은 Linux Foundation과 협력하여 설립됐으며, Global Synchronizer의 governance를 조정하고 Global Synchronizer ecosystem의 성장을 주도합니다. CF는 Super Validator governance와 운영의 투명성을 제공합니다. 또한 Super Validator node를 운영하며 회원을 대신해 governance vote에 참여합니다.

## Super Validators

Super Validator는 Global Synchronizer의 decentralized interoperability 및 synchronization infrastructure를 구성하는 핵심입니다. 다음 활동을 통해 Global Synchronizer의 integrity, security 및 운영 reliability를 보장합니다.

- Global Synchronizer의 핵심 infrastructure 실행
- Network 전반의 transaction sequencing
- Canton Coin transaction validation
- Network governance 및 의사 결정 참여

## Validators

Validator는 더 광범위한 Canton Network 안에서 작동합니다. Canton Network는 각 node가 필요한 data만 저장하고 Synchronizer를 통해 다른 Validator와 상호 작용하는 "network of networks"입니다. Validator는 일반적으로 하나 이상의 Synchronizer에 연결하여 encrypted message를 수신하고 확인합니다. 이 Synchronizer는 centralized 또는 decentralized service로 운영될 수 있습니다.

Global Synchronizer ecosystem에서 Validator의 주요 역할은 다음과 같습니다.

- Transaction validation
- Activity 기록
- User 및 application을 위한 network connectivity 제공
- Upgrade 및 migration 조정

## Tokenomics

Canton Coin은 burn-mint equilibrium mechanism을 통해 application builder, user 및 infrastructure provider가 Global Synchronizer를 사용하도록 incentive를 제공합니다. User는 Synchronizer traffic 비용을 지불하기 위해 Canton Coin을 burn하고, Validator, Super Validator 및 application provider는 infrastructure, application, usage 및 liveness contribution의 대가로 새로운 Canton Coin을 mint합니다.

Traffic fee mechanism과 CC-USD conversion rate를 포함한 전체 economic model은 [Global Synchronizer의 Tokenomics](/overview/reference/tokenomics-of-gs)를 참조하세요.
