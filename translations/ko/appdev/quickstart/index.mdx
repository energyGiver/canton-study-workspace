[Canton Network QuickStart](https://github.com/digital-asset/cn-quickstart) (cn-quickstart)는 local machine에서 작동하는 Canton Network 환경을 제공하는 reference application입니다. Daml model, Java backend service, React frontend, simulated Global Synchronizer node가 포함된 local Canton sandbox, 자체 application을 구축하고 테스트하기 위한 developer tooling이 포함되어 있습니다.

QuickStart는 App Provider가 App User용 license를 생성하고 App User가 갱신을 요청하거나 Canton Coin으로 결제하는 software licensing workflow를 보여줍니다. 이 workflow에는 production Canton Network application에서 사용하게 될 multi-party agreement, propose-accept flow, token transfer 등의 핵심 pattern이 포함됩니다.

## 제공되는 항목

QuickStart는 다음 항목을 포함하는 LocalNet이라는 local environment를 구성합니다.

- super-validator node, Sequencer, Mediator가 포함된 **simulated Canton Network**
- licensing application을 포함한 Participant Node를 실행하는 **App Provider node**
- wallet과 별도의 Participant Node를 실행하는 **App User node**
- provider 및 user role용 **React frontend**
- Ledger API interaction을 처리하는 **Java backend** service
- traffic 구매 및 결제 flow를 위한 **Canton Coin wallet**
- debugging 및 troubleshooting을 위한 [lnav](/appdev/quickstart/lnav) 기반 **log 분석**

## 시작하기 전에

QuickStart는 Module 1 (Canton 이해하기)의 개념에 익숙하며, 가능하면 Module 3 (Daml smart contract)도 이해하고 있다고 가정합니다. demo를 실행하기 위해 Daml 전문가일 필요는 없지만 template, choice, multi-party authorization을 이해하면 application의 동작을 파악하는 데 도움이 됩니다.

<Note>
QuickStart repository는 자체 Canton Network application을 구축할 때 권장하는 출발점입니다. demo를 실행한 후 Daml model, backend, frontend를 수정해 자체 business logic을 구현할 수 있습니다.
</Note>
