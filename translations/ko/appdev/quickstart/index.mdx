[Canton Network QuickStart](https://github.com/digital-asset/cn-quickstart)(cn-quickstart)는 local machine에서 작동하는 Canton Network 구성을 제공하는 reference application입니다. Daml model, Java backend service, React frontend, simulated Global Synchronizer node가 포함된 local Canton sandbox, 자체 application을 build 및 test하기 위한 developer tooling을 포함합니다.

QuickStart는 App Provider가 App User를 위한 license를 생성하고, App User가 renewal을 요청하고 Canton Coin으로 payment를 수행하는 software licensing workflow를 보여줍니다. 이 workflow는 production Canton Network application에서 사용하는 핵심 pattern인 multi-party agreement, propose-accept flow 및 token transfer를 다룹니다.

## 제공되는 항목

QuickStart는 LocalNet이라는 local environment를 다음과 같이 구성합니다.

- super-validator node, Sequencer 및 Mediator가 포함된 **simulated Canton Network**
- licensing application과 함께 Participant Node를 실행하는 **App Provider node**
- wallet과 별도의 Participant Node를 실행하는 **App User node**
- provider 및 user role을 위한 **React frontend**
- Ledger API interaction을 처리하는 **Java backend** service
- traffic 구매 및 payment flow를 위한 **Canton Coin wallet**
- debugging 및 troubleshooting을 위한 [lnav](/appdev/quickstart/lnav) 기반 **log 분석**

## 시작하기 전에

QuickStart는 Module 1(Canton 이해하기)의 concept에 익숙하고 가급적 Module 3(Daml Smart Contract)도 알고 있다고 가정합니다. demo를 실행하는 데 Daml 전문가일 필요는 없지만 template, choice 및 multi-party authorization을 이해하면 application의 동작을 파악하는 데 도움이 됩니다.

<Note>
QuickStart repository는 자체 Canton Network application을 구축할 때 권장하는 출발점입니다. demo를 실행한 뒤 Daml model, backend 및 frontend를 수정해 자체 business logic을 구현할 수 있습니다.
</Note>
