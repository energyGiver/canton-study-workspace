# DA.Time

이 module은 Time 값을 조작하는 function 집합을 제공합니다.

`Time` type은 UTC의 특정 datetime을 표현합니다. 예: `time (date 2007 Apr 5) 14 30 05`.

Time의 범위는 0001-01-01T00:00:00.000000Z에서 9999-12-31T23:59:59.999999Z까지입니다.
