### `data CallStack`

`HasCallStack` constraint에서 자동으로 구성되는 callstack type입니다.

`callStack`으로 현재 callstack을 얻고, `getCallStack`으로 `CallStack`을 deconstruct할 수 있습니다.

<span id="type-ghc-stack-types-hascallstack-63713"></span>

### `type HasCallStack`

= `IP` `callStack` [`CallStack`](#type-ghc-stack-types-callstack-86244)

`CallStack`을 요청합니다. error와 debug message에서 더 유용한 callstack을 얻으려면 type signature의 constraint로 사용하세요.

예를 들어 다음 type signature를 선언하는 대신,

```
myFunction : Int -> Update ()
```

`HasCallStack` constraint가 있는 type signature를 선언할 수 있습니다.

```
myFunction : HasCallStack => Int -> Update ()
```

function `myFunction`의 호출 방식은 같지만, `callStack`으로 얻을 수 있는 현재 callstack의 entry로도 표시됩니다.

`HasCallStack` constraint가 있는 function만 현재 callstack에 추가됩니다. function에 `HasCallStack` constraint가 없으면 그 function 내부에서 callstack이 reset됩니다.
