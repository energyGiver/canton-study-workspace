# DA.Either

`Either` type은 두 가지 가능성을 가진 값을 표현합니다.

정상 값 또는 error인 값을 표현하는 데 사용되기도 합니다. 관례상 `Left` constructor는 error 값을 담고, `Right` constructor는 정상 값을 담는 데 사용됩니다. 연상법으로 "right"는 옮다는 뜻도 가집니다.
