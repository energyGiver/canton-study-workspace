# DA.NonEmpty.Types

이 module에는 non-empty list에 안정적인 package ID를 부여하기 위한 type이 포함되어 있습니다.

이 type은 DA.NonEmpty에서 re-export되므로 이 module을 직접 import할 필요가 없습니다.

### `data NonEmpty a`

`NonEmpty`는 non-empty list의 type입니다. 다시 말해 항상 최소 하나의 element를 포함하는 list의 type입니다. `x`가 non-empty list이면 `x.hd`로 첫 번째 element를, `x.tl`로 list의 나머지를 얻을 수 있습니다.
