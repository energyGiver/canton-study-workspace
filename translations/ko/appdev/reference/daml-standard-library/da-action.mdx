### `when`

`when` : [`Applicative`](/appdev/reference/daml-standard-library/prelude#class-da-internal-prelude-applicative-9257) `f` => [`Bool`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-bool-66265) -> `f` () -> `f` ()

`Action` expression을 조건에 따라 실행합니다. 예:
```
  when final (archive contractId)
```
Boolean 값 `final`이 `True`이면 contract `contractId`를 archive하고, 그렇지 않으면 아무 작업도 하지 않습니다.

이 function에는 short-circuiting semantics가 있습니다. 즉 두 argument가 모두 있고 첫 번째 argument가 `False`로 평가되면 두 번째 argument는 전혀 평가되지 않습니다.

### `filterA`
