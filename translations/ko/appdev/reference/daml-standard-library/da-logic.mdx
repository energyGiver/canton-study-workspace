## Data Types

<span id="type-da-logic-types-formula-34794"></span>

### `data Formula t`

`Formula t`는 type t의 proposition을 갖는 propositional calculus의 formula입니다.

Constructor:

<span id="constr-da-logic-types-proposition-6173"></span>
- `Proposition t`

`Proposition p`는 formula p입니다.
<span id="constr-da-logic-types-negation-48969"></span>
- `Negation (Formula t)`

formula f에 대해 `Negation f`는 ¬f입니다.
<span id="constr-da-logic-types-conjunction-51637"></span>
- `Conjunction [Formula t]`

formula f1, ..., fn에 대해 `Conjunction [f1, ..., fn]`은 f1 ∧ ... ∧ fn입니다.
<span id="constr-da-logic-types-disjunction-65549"></span>
- `Disjunction [Formula t]`

formula f1, ..., fn에 대해 `Disjunction [f1, ..., fn]`은 f1 ∨ ... ∨ fn입니다.

<span id="function-da-logic-substitute-65872"></span>

### `substitute`

`substitute` : (`t` -> [`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) [`Bool`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-bool-66265)) -> [`Formula`](#type-da-logic-types-formula-34794) `t` -> [`Formula`](#type-da-logic-types-formula-34794) `t`

`substitute`는 truth assignment를 받아 formula의 해당 위치에 `True` 또는 `False`를 대체합니다.

<span id="function-da-logic-reduce-40218"></span>

### `reduce`

`reduce` : [`Formula`](#type-da-logic-types-formula-34794) `t` -> [`Formula`](#type-da-logic-types-formula-34794) `t`

`reduce`는 다음 방법으로 formula를 가능한 한 최대한 단순화합니다.
1. `true`와 `false`의 모든 occurrence를 제거합니다.
2. 직접 중첩된 Conjunction과 Disjunction을 제거합니다.
3. negation normal form으로 변환합니다.

<span id="function-da-logic-isbool-80820"></span>

### `isBool`

`isBool` : [`Formula`](#type-da-logic-types-formula-34794) `t` -> [`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) [`Bool`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-bool-66265)

`isBool`은 formula를 bool로 변환하려고 시도합니다. `isBool true == Some True`와 `isBool false == Some False`를 만족합니다. 그 외에는 `None`을 반환합니다.

`interpret`는 truth function으로 먼저 substitute한 다음 가능한 한 최대한 reduce하는 `toBool` 버전입니다.
