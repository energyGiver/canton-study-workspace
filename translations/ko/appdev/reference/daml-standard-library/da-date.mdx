# DA.Date

이 module은 Date 값을 조작하는 function 집합을 제공합니다.

Date의 범위는 0001-01-01T00:00:00.000000Z에서 9999-12-31T23:59:59.999999Z까지입니다.

### `date`

`date` : [`Int`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-int-37261) -> [`Month`](#type-da-date-types-month-22803) -> [`Int`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-int-37261) -> [`Date`](/appdev/reference/daml-standard-library/prelude#type-da-internal-lf-date-32253)

세 값 year, month, day가 주어지면 `Date` 값을 구성합니다. `date y m d`는 year `y`, month `m`, day `d`를 `Date` 값으로 변환합니다. `d`가 `1 .. monthDayCount y m` 범위 밖이면 error를 발생시킵니다.

<span id="function-da-date-todateutc-87953"></span>

### `toDateUTC`

`toDateUTC` : [`Time`](/appdev/reference/daml-standard-library/prelude#type-da-internal-lf-time-63886) -> [`Date`](/appdev/reference/daml-standard-library/prelude#type-da-internal-lf-date-32253)

UTC time에서 UTC date를 추출합니다.

이 function은 Time을 Date로 truncate하지만 많은 경우 실제로 원하는 date를 반환하지 않습니다. 보통 Time의 source가 getTime이고, getTime은 UTC를 반환하며, 원하는 date는 특정 위치나 exchange의 local date일 가능성이 크기 때문입니다. 따라서 예를 들어 Singapore에서 market이 열릴 때 이 방법으로 date를 가져오면 어제 date가 될 수 있습니다.
