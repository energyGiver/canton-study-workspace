# DA.Optional

`Optional` type은 선택적 값을 encapsulate합니다. `Optional a` type의 값은 `a` type의 값을 포함하거나, `Some a`로 표현되며, 비어 있거나, `None`으로 표현됩니다. `Optional`을 사용하면 error 같은 과격한 방법에 의존하지 않고 error나 예외적인 경우를 다룰 수 있습니다.

Optional type은 action이기도 합니다. 모든 error를 `None`으로 표현하는 간단한 error action입니다. `Either` type을 사용하면 더 풍부한 error action을 만들 수 있습니다.

### `mapOptional`

`mapOptional` : (`a` -> [`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) `b`) -> [`a`] -> [`b`]

`mapOptional` function은 element를 제외할 수 있는 `map` 버전입니다. function argument는 `Optional b` type을 반환합니다. 결과가 `None`이면 결과 list에 element를 추가하지 않고, `Some b`이면 결과 list에 `b`를 포함합니다.

<span id="function-da-optional-findoptional-83634"></span>

### `findOptional`

`findOptional` : (`a` -> [`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) `b`) -> [`a`] -> [`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) `b`

`findOptional`은 predicate가 처음으로 `Some`을 반환하는 element에서 predicate의 값을 반환합니다. `findOptional`은 `find`와 비슷하지만 predicate에서 값을 반환할 수 있습니다. predicate가 pattern match에 해당할 때 더 type-safe한 버전으로 사용하거나, predicate에서 수행한 작업의 중복을 피해 성능을 높이는 데 유용합니다.
