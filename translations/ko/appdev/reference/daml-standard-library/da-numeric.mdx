## Data Types

<span id="type-da-numeric-roundingmode-53864"></span>

### `data RoundingMode`

Rounding mode입니다.

Constructor:

<span id="constr-da-numeric-roundingup-99831"></span>
- `RoundingUp`

0에서 멀어지는 방향으로 rounding합니다.
<span id="constr-da-numeric-roundingdown-63242"></span>
- `RoundingDown`

0을 향하는 방향으로 rounding합니다.
<span id="constr-da-numeric-roundingceiling-67218"></span>
- `RoundingCeiling`

양의 무한대를 향하는 방향으로 rounding합니다.
<span id="constr-da-numeric-roundingfloor-71675"></span>
- `RoundingFloor`

음의 무한대를 향하는 방향으로 rounding합니다.
<span id="constr-da-numeric-roundinghalfup-22532"></span>
- `RoundingHalfUp`

가장 가까운 이웃 값으로 rounding하되, 두 이웃 값의 거리가 같으면 0에서 멀어지는 방향으로 rounding합니다.
<span id="constr-da-numeric-roundinghalfdown-91305"></span>
- `RoundingHalfDown`

가장 가까운 이웃 값으로 rounding하되, 두 이웃 값의 거리가 같으면 0을 향하는 방향으로 rounding합니다.
<span id="constr-da-numeric-roundinghalfeven-70729"></span>
- `RoundingHalfEven`

가장 가까운 이웃 값으로 rounding하되, 두 이웃 값의 거리가 같으면 짝수인 이웃 값으로 rounding합니다.
<span id="constr-da-numeric-roundingunnecessary-42017"></span>
- `RoundingUnnecessary`

rounding하지 않습니다. 대상 scale에서 rounding 없이 결과를 표현할 수 없으면 error를 발생시킵니다.

### `mul`

<span id="function-da-numeric-roundnumeric-41344"></span>

### `roundNumeric`

`roundNumeric` : [`NumericScale`](/appdev/reference/daml-standard-library/prelude#class-ghc-classes-numericscale-83720) `n` => [`Int`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-int-37261) -> [`RoundingMode`](#type-da-numeric-roundingmode-53864) -> [`Numeric`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-numeric-891) `n` -> [`Numeric`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-numeric-891) `n`

`Numeric` 숫자를 rounding합니다. `round n r a`의 값은 `a`를 rounding mode `r`에 따라 소수점 이하 `n`자리, 즉 scale `n`으로 rounding한 값입니다.

`n`자리 이하의 소수로 정확히 표현할 수 없는 숫자에 `RoundingUnnecessary` mode를 사용하면 실패합니다.
