### `class Bifunctor p`

bifunctor는 두 개의 type argument를 받고 양쪽 argument *모두*에서 functor인 type constructor입니다. 즉 `Functor`와는 달리 `Either`와 같은 type constructor는 `Bifunctor` instance를 위해 부분 적용할 필요가 없습니다. 이 class의 method를 사용하면 Left 값, `Right` 값 또는 두 값 모두에 function을 mapping할 수 있습니다.

첫 번째와 두 번째 argument가 모두 covariant인 bifunctor입니다.

`bimap`을 정의하거나 `first`와 `second`를 모두 정의해 `Bifunctor`를 정의할 수 있습니다.

`bimap`을 제공하는 경우 다음을 보장해야 합니다.

```daml-force
`bimap identity identity` ≡ `identity`
```

`first`와 `second`를 제공하는 경우 다음을 보장해야 합니다.

```daml-force
first identity ≡ identity
second identity ≡ identity

```

모두 제공하는 경우 다음도 보장해야 합니다.

```daml-force
bimap f g ≡ first f . second g
```

parametricity에 따라 이 조건들은 다음을 보장합니다.

```daml-force

bimap  (f . g) (h . i) ≡ bimap f h . bimap g i
first  (f . g) ≡ first  f . first  g
second (f . g) ≡ second f . second g

```

Method:

- `bimap` : (`a` -> `b`) -> (`c` -> `d`) -> `p` `a` `c` -> `p` `b` `d`
  두 argument에 동시에 mapping을 적용합니다.

  ```daml-force
  bimap f g ≡ first f . second g
  ```

  예:

  ```
  >>> bimap not (+1) (True, 3)
  (False,4)

  >>> bimap not (+1) (Left True)
  Left False

  >>> bimap not (+1) (Right 3)
  Right 4
  ```
- `first` : (`a` -> `b`) -> `p` `a` `c` -> `p` `b` `c`
  첫 번째 argument에 covariant mapping을 적용합니다.

  ```daml-force
  first f ≡ bimap f identity
  ```

  예:

  ```
  >>> first not (True, 3)
  (False,3)

  >>> first not (Left True : Either Bool Int)
  Left False
  ```
- `second` : (`b` -> `c`) -> `p` `a` `b` -> `p` `a` `c`
  두 번째 argument에 covariant mapping을 적용합니다.

  ```daml-force
  second ≡ bimap identity
  ```

  예:

  ```
  >>> second (+1) (True, 3)
  (True,4)

  >>> second (+1) (Right 3 : Either Bool Int)
  Right 4
  ```
