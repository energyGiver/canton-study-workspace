# DA.Traversable

왼쪽에서 오른쪽으로 traverse하며 각 element에 action을 수행할 수 있는 data structure의 class입니다.

`Prelude`에 정의된 function과의 충돌을 피하기 위해 보통은 이 module을 qualified import하는 것이 좋습니다. 예:

```

import DA.Traversable   qualified as F

```
