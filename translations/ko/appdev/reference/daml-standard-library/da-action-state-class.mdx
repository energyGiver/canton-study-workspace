### `class ActionState s m`

Action `m`에는 type `s`의 state variable이 있습니다.

규칙:
  * `get *> ma  =  ma`
  * `ma <* get  =  ma`
  * `put a >>= get   =  put a $> a`
  * `put a *> put b  =  put b`
  * `(,) <$> get <*> get  =  get <&> \a -> (a, a)`

비공식적으로 이 규칙들은 일반적인 할당 가능 변수와 같이 동작함을 의미합니다.
값을 조회한다고 마법처럼 변하지 않고, 특정 값을 넣으면 이후 읽을 때도 항상 그 값을 얻으며, 값을 할당하고도 그 값을 한 번도 읽지 않으면 해당 할당은 효과가 없는 등의 성질을 가집니다.

Method:

- `get` : `m` `s`
  state variable의 현재 값을 가져옵니다.
- `put` : `s` -> `m` ()
  state variable의 값을 설정합니다.
- `modify` : (`s` -> `s`) -> `m` ()
  주어진 function으로 state variable을 변경합니다.
- `modify` : [`Action`](/appdev/reference/daml-standard-library/prelude#class-da-internal-prelude-action-68790) `m` => (`s` -> `s`) -> `m` ()
