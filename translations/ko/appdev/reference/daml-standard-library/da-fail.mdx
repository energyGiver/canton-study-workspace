## Data Types

<span id="type-da-internal-fail-types-failurecategory-97811"></span>

### `data FailureCategory`

failure의 status code와 log level을 결정하는 category입니다. https://docs.digitalasset.com/operate/3.4/reference/error_codes.html#error-categories-inventory에 documentation된 Canton error category와 1:1로 mapping됩니다.

gRPC error code에 더 익숙하다면 comment에 참조된 synonym을 사용할 수 있습니다.

Constructor:

<span id="constr-da-internal-fail-types-invalidindependentofsystemstate-84432"></span>
- `InvalidIndependentOfSystemState`

현재 ledger state와 무관하며 retry해서는 안 되는 error를 report할 때 사용합니다.

gRPC status code `INVALID_ARGUMENT`에 해당합니다.

자세한 내용은 https://docs.digitalasset.com/operate/3.4/reference/error_codes.html#invalidindependentofsystemstate를 참조하세요.
<span id="constr-da-internal-fail-types-invalidgivencurrentsystemstateother-6547"></span>
- `InvalidGivenCurrentSystemStateOther`

현재 ledger state로 인해 발생하지만 ledger state가 변경되면 사라질 수 있는 error를 report할 때 사용합니다. client는 ledger에서 updated state를 읽은 뒤 이 request를 retry해야 합니다.

gRPC status code `FAILED_PRECONDITION`에 해당합니다.

자세한 내용은 https://docs.digitalasset.com/operate/3.4/reference/error_codes.html#error-categories-inventory를 참조하세요.

### `data FailureStatus`

Constructor:

<span id="constr-da-internal-fail-types-failurestatus-61878"></span>
- `FailureStatus`

<ResponseField name="errorId" type="Text">
error의 명확한 identifier입니다.

app provider를 식별하는 DNS name 또는 error를 정의하는 API standard를 prefix로 사용해야 합니다.

예를 들어 CN token standard context에서 자금 부족 error를 report하려면 `splice.lfdecentralizedtrust.org/insufficient-funds`를 사용할 수 있습니다.
</ResponseField>

<ResponseField name="category" type="FailureCategory">
client가 error를 처리해야 하는 방식을 결정하는 failure category입니다.
</ResponseField>

<ResponseField name="message" type="Text">
developer용 error message이며 영어로 작성해야 합니다.
</ResponseField>

<ResponseField name="meta" type="TextMap Text">
key-value format의 machine-readable error metadata입니다.

error에 대한 추가 context를 client에 제공할 때 사용하세요.

그렇지 않으면 truncate될 수 있으므로 512자 미만이어야 합니다.
</ResponseField>
