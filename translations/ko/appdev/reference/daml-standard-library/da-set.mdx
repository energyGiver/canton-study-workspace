# DA.Set

참고: Daml-LF 1.11 이상에서만 지원됩니다.

이 module은 generic set type `Set k`와 관련 function을 export합니다. 이 module은 다음과 같이 qualified import해야 합니다.

```

import DA.Set (Set)

import DA.Set qualified as S

```

이렇게 하면 `Set` type과 여러 operation을 `S.lookup`, `S.insert`, `S.fromList` 등으로 사용할 수 있습니다.

`Set k`는 내부적으로 type `k`의 built-in order를 사용합니다. 이는 function을 포함한 key는 비교할 수 없고 runtime error를 일으킨다는 뜻입니다. 이를 방지하기 위해 대부분의 set operation에 `Ord k` instance가 필요합니다. `deriving`을 사용해 자동으로 derived된 `Ord k` instance가 있는 key type에만 `Set k`를 사용하는 것이 권장됩니다.

```

data K = ...

deriving (Eq, Ord)

```

여기에는 function type이 아닌 모든 built-in type과, `a`와 `b`에 default `Ord` instance가 있는 `Int`, `Text`, `Bool`, `(a, b)`, `t`에 default `Ord` instance가 있는 `Optional t`와 `[t]`, `k`와 `v`에 default `Ord` instance가 있는 `Map k v`, `k`에 default `Ord` instance가 있는 `Set k`가 포함됩니다.
