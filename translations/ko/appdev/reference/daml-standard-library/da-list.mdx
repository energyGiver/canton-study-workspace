### `sort`

`sort` : [`Ord`](/appdev/reference/daml-standard-library/prelude#class-ghc-classes-ord-6395) `a` => [`a`] -> [`a`]

`sort` function은 stable sorting algorithm을 구현합니다. programmer가 직접 comparison function을 제공할 수 있는 `sortBy`의 special case입니다.

element는 낮은 값부터 높은 값 순으로 정렬되며 duplicate는 input에 나타난 순서를 유지합니다(stable sort).

### `minimumBy`

<span id="function-da-list-sorton-99758"></span>

### `sortOn`

`sortOn` : [`Ord`](/appdev/reference/daml-standard-library/prelude#class-ghc-classes-ord-6395) `k` => (`a` -> `k`) -> [`a`] -> [`a`]

각 element에 key function을 적용한 결과를 비교해 list를 정렬합니다. `sortOn f`는 `sortBy (comparing f)`와 동일하지만 input list의 각 element에 대해 `f`를 한 번만 평가하므로 성능상 이점이 있습니다. 이를 decorate-sort-undecorate paradigm이라고도 합니다.

element는 낮은 값부터 높은 값 순으로 정렬되며 duplicate는 input에 나타난 순서를 유지합니다.

### `foldBalanced1`

`foldBalanced1` : (`a` -> `a` -> `a`) -> [`a`] -> `a`

비어 있지 않은 list를 balanced 방식으로 fold합니다. balanced란 각 element가 operator tree에서 거의 같은 depth를 갖는다는 뜻입니다. 거의 같은 depth란 최대 depth와 최소 depth의 차이가 1 이하여야 한다는 의미입니다. `foldl1` 또는 `foldr1`과 동일한 결과를 얻으려면 accumulation operation이 associative하고 commutative해야 합니다.

["b","n","a","n","a"]
```

programmer가 직접 equality test를 제공할 수 있는 'deleteBy'의 special case입니다.

<span id="function-da-list-deleteby-50465"></span>

### `deleteBy`

`deleteBy` : (`a` -> `a` -> [`Bool`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-bool-66265)) -> `a` -> [`a`] -> [`a`]

'deleteBy' function은 'delete'처럼 동작하지만 user가 제공한 equality predicate를 받습니다.

```
> deleteBy (<=) 4 [1..10]
[1,2,3,5,6,7,8,9,10]
```

<span id="function-da-list-x-54181"></span>

### `\\`

`\\` : [`Eq`](/appdev/reference/daml-standard-library/prelude#class-ghc-classes-eq-22713) `a` => [`a`] -> [`a`] -> [`a`]

`\\` function은 list difference(non-associative)입니다.
`xs \\ ys`의 결과에서는 `ys`의 각 element가 나타나는 순서대로 `xs`에서 해당 element가 처음 나타나는 항목(있는 경우)을 제거합니다. 따라서

```
(xs ++ ys) \\ xs == ys
```

크기가 _n_ 및 _m_인 list가 주어질 때 이 function은 _O(n*m)_입니다.

`singleton` : `a` -> [`a`]

singleton list를 생성합니다.

>>> singleton True

```

<span id="function-da-list-bangbang-90127"></span>

### `!!`

`!!` : [`a`] -> [`Int`](/appdev/reference/daml-standard-library/prelude#type-ghc-types-int-37261) -> `a`

0부터 시작하는 list index(subscript) operator입니다.
예를 들어 `xs !! 2`는 `xs`의 세 번째 element를 반환합니다.
index가 주어진 list에 적합하지 않으면 error를 발생시킵니다.
array indexing이 _O(1)_인 Java 같은 language와 달리, 이 function의 complexity는 주어진 index를 _n_이라 할 때 _O(n)_입니다.
