# DA.Map

참고: Daml-LF 1.11 이상에서만 지원됩니다.

이 module은 generic map type `Map k v`와 관련 function을 export합니다. 이 module은 다음과 같이 qualified import해야 합니다:

```

import DA.Map (Map)

import DA.Map qualified as M

```

이렇게 하면 `Map` type과 여러 operation을 `M.lookup`, `M.insert`, `M.fromList` 등으로 사용할 수 있습니다.

`Map k v`는 내부적으로 type `k`의 built-in order를 사용합니다.

이는 function을 포함하는 key는 비교할 수 없고 runtime error를 일으킨다는 뜻입니다. 이를 방지하기 위해 대부분의 map operation에는 `Ord k` instance가 필요합니다. `deriving`을 사용해 자동으로 derived된 `Ord k` instance가 있는 key type에만 `Map k v`를 사용하는 것이 권장됩니다:

```

data K = ...

deriving (Eq, Ord)

```

여기에는 function type이 아닌 모든 built-in type이 포함됩니다. 예를 들면 `Int`, `Text`, `Bool`, `a`와 `b`에 default `Ord` instance가 있는 `(a, b)`, `t`에 default `Ord` instance가 있는 `Optional t`와 `[t]`, `k`와 `v`에 default `Ord` instance가 있는 `Map k v`, `k`에 default `Ord` instance가 있는 `Set k`입니다.

### `fromListWithL`

`fromListWithL` : [`Ord`](/appdev/reference/daml-standard-library/prelude#class-ghc-classes-ord-6395) `k` => (`v` -> `v` -> `v`) -> [(`k`, `v`)] -> [`Map`](/appdev/reference/daml-standard-library/prelude#type-da-internal-lf-map-90052) `k` `v`

combining function을 사용해 key/value pair list에서 map을 생성합니다. combining function은 list에 key가 여러 번 나타날 때만 사용되며 두 argument를 받습니다. 첫 번째는 해당 key에 새로 insert되는 값이고 두 번째는 해당 key에 지금까지 accumulate된 값입니다.
예:

```
>>> fromListWithL (++) [("A", [1]), ("A", [2]), ("B", [2]), ("B", [1]), ("A", [3])]
fromList [("A", [3, 2, 1]), ("B", [1, 2])]
>>> fromListWithL (++) [] == (empty : Map Text [Int])
True
```

### `keys`

`keys` : [`Map`](/appdev/reference/daml-standard-library/prelude#type-da-internal-lf-map-90052) `k` `v` -> [`k`]

map의 key list를 가져옵니다. key는 type `k`의 built-in order에 따라 sort되며, `deriving Ord`를 사용할 때 `Ord k` instance와 일치합니다.

```
>>> keys (fromList [("A", 1), ("C", 3), ("B", 2)])
["A", "B", "C"]
```

### `alter`

`alter` : [`Ord`](/appdev/reference/daml-standard-library/prelude#class-ghc-classes-ord-6395) `k` => ([`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) `v` -> [`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) `v`) -> `k` -> [`Map`](/appdev/reference/daml-standard-library/prelude#type-da-internal-lf-map-90052) `k` `v` -> [`Map`](/appdev/reference/daml-standard-library/prelude#type-da-internal-lf-map-90052) `k` `v`

`m`의 `k`에 있는 value를 `f`로 update하며 필요에 따라 insert하거나 delete합니다. `f`는 `k`의 value와 함께 호출되며, value가 없으면 `None`과 함께 호출됩니다. `f`는 `m`에 insert할 새 value를 담은 `Some`을 반환하여 기존 value가 있으면 바꾸거나, `None`을 반환하여 `m`의 `k` association을 제거할 수 있습니다.

이 동작이 의미하는 바는 다음과 같습니다:

  alter identity k = identity
  alter g k . alter f k = alter (g . f) k
  alter (\_ -> Some v) k = insert k v
  alter (\_ -> None) = delete
