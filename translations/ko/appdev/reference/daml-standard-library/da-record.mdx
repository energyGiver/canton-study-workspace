## Data Types

<span id="type-da-internal-record-hasfield-59910"></span>

### `type HasField x r a`

= ([`GetField`](#class-da-internal-record-getfield-53979) `x` `r` `a`, [`SetField`](#class-da-internal-record-setfield-4311) `x` `r` `a`)

`HasField`는 `GetField`와 `SetField`의 class synonym이며, 각각 각 record field에 대한
getter 및 setter function을 자동으로 제공합니다.

**대부분의 use case에서는 일반 Record syntax를 사용하는 것이 좋습니다**:

```
daml> let a = MyRecord 1 "hello"
daml> a.foo
1
daml> a.bar
"hello"
daml> a { bar = "bye" }
MyRecord {foo = 1, bar = "bye"}
daml> a with foo = 3
MyRecord {foo = 3, bar = "hello"}
daml>
```

Record syntax에 대한 자세한 내용은 https://docs.digitalasset.com/build/3.4/reference/daml/stdlib/DA-Record.html 을 참조하세요.

`GetField x r a`와 `SetField x r a`는 세 parameter를 받는 typeclass입니다. 첫 번째
parameter `x`는 field name이고, 두 번째 parameter `r`은 record type이며,
마지막 parameter `a`는 이 record의 field type입니다. 예를 들어 다음 type을 정의하면:

```
data MyRecord = MyRecord with
    foo : Int
    bar : Text
```

그러면 다음 GetField 및 SetField instance가 자동으로 생성됩니다:

```
GetField "foo" MyRecord Int
SetField "foo" MyRecord Int
GetField "bar" MyRecord Text
SetField "bar" MyRecord Text
```

value를 가져오려면 class `GetField`의 `getField` method를 사용할 수 있습니다:

```
getFoo : MyRecord -> Int
getFoo r = getField @"foo" r

getBar : MyRecord -> Text
getBar r = getField @"bar" r
```

field name을 지정하는 데 “type application” syntax( `f @t` )를 사용한다는 점에 유의하세요.

마찬가지로 field의 value를 설정하려면 class `SetField`의 `setField` method를 사용할 수 있습니다:

```
setFoo : Int -> MyRecord -> MyRecord
setFoo a r = setField @"foo" a r

setBar : Text -> MyRecord -> MyRecord
setBar a r = setField @"bar" a r
```
