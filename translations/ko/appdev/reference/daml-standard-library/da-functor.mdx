### `<&>`

`<&>` : [`Functor`](/appdev/reference/daml-standard-library/prelude#class-ghc-base-functor-31205) `f` => `f` `a` -> (`a` -> `b`) -> `f` `b`

functor에 function을 mapping합니다. 값 `as`와 function `f`가 주어지면 `as <&> f`는 `f <$> as`입니다. 즉 `<&>`는 `<$>`와 비슷하지만 argument 순서가 반대입니다.
