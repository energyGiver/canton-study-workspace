# DA.NonEmpty

non-empty list을 위한 type과 function입니다. 이 module은 prelude list function과 이름이 같은 많은 function을 re-export하므로 module을 qualified import하는 것이 예상됩니다.

예를 들어 다음 import list를 사용하면 `NonEmpty` type에 접근할 수 있고, non-empty list의 function은 `NE.append, NE.map, NE.foldl`처럼 qualified됩니다.

```

import DA.NonEmpty (NonEmpty)

import qualified DA.NonEmpty as NE

```
