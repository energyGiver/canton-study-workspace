<span id="function-da-list-total-foldbalanced1-85298"></span>

### `foldBalanced1`

`foldBalanced1` : (`a` -> `a` -> `a`) -> [`a`] -> [`Optional`](/appdev/reference/daml-standard-library/prelude#type-da-internal-prelude-optional-37153) `a`

non-empty list를 balanced 방식으로 fold합니다. balanced란 각 element가 operator tree에서 거의 같은 depth를 갖는다는 뜻입니다. 거의 같은 depth란 최대 depth와 최소 depth의 차이 1 이하임을 의미합니다. `foldl1` 또는 `foldr1`과 같은 결과를 얻으려면 accumulation operation이 associative이고 commutative여야 합니다.

list가 비어 있으면 `None`을 반환합니다.
