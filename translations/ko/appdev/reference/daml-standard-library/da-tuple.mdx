## Functions

<span id="function-da-tuple-first-48871"></span>

### `first`

`first` : (`a` -> `a'`) -> (`a`, `b`) -> (`a'`, `b`)

프로그래머가 제공한 function을 argument pair의 첫 번째 field에 적용해 얻은 pair입니다.

<span id="function-da-tuple-second-48360"></span>

### `second`

`second` : (`b` -> `b'`) -> (`a`, `b`) -> (`a`, `b'`)

프로그래머가 제공한 function을 argument pair의 두 번째 field에 적용해 얻은 pair입니다.

<span id="function-da-tuple-both-63511"></span>

### `both`

`both` : (`a` -> `b`) -> (`a`, `a`) -> (`b`, `b`)

프로그래머가 제공한 function을 argument pair의 첫 번째와 두 번째 field 모두에 적용해 얻은 pair입니다.

<span id="function-da-tuple-swap-76115"></span>

### `swap`

`swap` : (`a`, `b`) -> (`b`, `a`)

argument pair의 첫 번째와 두 번째 field 순서를 바꿔 얻은 pair입니다.

<span id="function-da-tuple-dupe-14430"></span>

### `dupe`

`dupe` : `a` -> (`a`, `a`)

하나의 값을 복제해 pair로 만듭니다.

> dupe 12 == (12, 12)

<span id="function-da-tuple-fst3-84676"></span>

### `fst3`

`fst3` : (`a`, `b`, `c`) -> `a`

triple에서 'fst'를 추출합니다.

<span id="function-da-tuple-snd3-63950"></span>

### `snd3`

`snd3` : (`a`, `b`, `c`) -> `b`

triple에서 'snd'를 추출합니다.

<span id="function-da-tuple-thd3-58697"></span>

### `thd3`

`thd3` : (`a`, `b`, `c`) -> `c`

triple의 마지막 element를 추출합니다.

<span id="function-da-tuple-curry3-2900"></span>

### `curry3`

`curry3` : ((`a`, `b`, `c`) -> `d`) -> `a` -> `b` -> `c` -> `d`

uncurried function을 curried function으로 변환합니다.

<span id="function-da-tuple-uncurry3-51859"></span>

### `uncurry3`

`uncurry3` : (`a` -> `b` -> `c` -> `d`) -> (`a`, `b`, `c`) -> `d`

curried function을 triple에 적용되는 function으로 변환합니다.
