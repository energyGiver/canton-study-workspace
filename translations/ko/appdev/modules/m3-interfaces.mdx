# Interface

Daml에서 interface는 view type, method signature, choice로 지정되는 behavior와 함께 abstract type을 정의합니다. template이 interface를 준수하려면 special `view` method를 포함해 interface의 모든 method를 구현하는 해당 `interface instance` definition이 있어야 합니다. 그러면 다른 developer가 concrete template 대신 interface를 기준으로 application을 작성할 수 있으므로 서로 다른 template으로 구축된 contract라도 같은 interface를 구현하면 interoperate할 수 있습니다.

interface를 사용하려면 Daml project가 Daml-LF version `1.15` 이상을 target으로 해야 하며 현재 default가 이 조건을 충족합니다. Canton을 사용한다면 Synchronizer의 protocol version이 `4` 이상이어야 합니다.

interface declaration, view type, interface choice, `interface instance` clause, required interface, `toInterface`/`fromInterface` 함수군을 포함한 전체 syntax는 Daml Language Reference의 [Reference: Interfaces](/appdev/reference/daml-language-reference#reference-interfaces)를 참고하세요.

## Canton Network의 Interface

interface는 Canton Network 전반의 interoperability에 핵심적인 역할을 합니다. 다음 두 Canton Improvement Proposal (CIP)은 application developer가 알아야 할 standard interface를 정의합니다.

- [CIP-0056 — Token Standard](https://github.com/canton-foundation/cips/blob/main/cip-0056/cip-0056.md): Canton Network의 fungible token을 위한 standard interface를 정의합니다. application에서 token을 발행하거나 transfer하는 경우 이 interface를 구현하면 ecosystem의 wallet 및 다른 application과 compatibility를 확보할 수 있습니다.

- [CIP-0103 — dApp Standard](https://github.com/mjuchli-da/cips/blob/cip-dapp-standard/cip-0103/cip-0103.md): decentralized application을 위한 standard interface를 정의합니다. 익숙한 ERC 방식의 pattern을 Daml interface에 매핑하므로 Ethereum 경험이 있는 developer에게 특히 관련이 깊습니다.

Canton Network에서 application을 구축할 때 이러한 standard interface를 구현하면 각 counterparty와 custom integration을 수행하지 않고도 contract가 더 넓은 ecosystem에 참여할 수 있습니다.
