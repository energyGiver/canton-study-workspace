Module 4는 Daml contract 작성과 완전한 application 출시 사이의 간극을 연결합니다. Canton application의 구조, 사용 가능한 SDK와 API, ledger와 interaction하는 backend 및 frontend component를 구축하는 방법을 학습합니다.

## 사전 요구 사항

이 module을 시작하기 전에 [Module 3: Daml Smart Contract](/appdev/modules/m3-dev-environment)를 완료해야 합니다. Daml의 template, choice, authorization을 실무적으로 이해해야 합니다. Java 또는 TypeScript에 익숙하면 도움이 되지만 필수는 아닙니다.

## 학습 내용

- Canton application architecture에서 role인 App Provider, App User, End User를 infrastructure에 매핑하는 방법
- ledger를 대상으로 개발할 때 사용할 수 있는 SDK, API, code generation tool
- Command를 submit하고 Transaction을 읽는 backend service 구축 방법
- contract data를 표시하고 wallet과 integrate하는 frontend 구축 방법
- application developer 관점에서 Canton Coin과 traffic이 작동하는 방식
