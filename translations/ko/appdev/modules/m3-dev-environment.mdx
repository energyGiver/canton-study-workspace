## 소개

Daml은 Canton ledger에서 composable application을 구축하도록 설계된 smart contract language입니다.

이 module에서는 asset holding 및 trading application을 구축하면서 Daml ledger의 구조와 Canton Network에서 실행되는 Daml application을 작성하는 방법을 학습합니다. 가장 중요한 language feature의 개요를 살펴보고 Daml developer tool을 사용해 application을 작성, test, compile, package, 배포하는 방법을 익힙니다.

## 사전 요구 사항

- [dpm](/sdks-tools/cli-tools/dpm)을 설치했습니다

## Example Code 불러오기

이 module의 각 section에서는 이전 section보다 더 많은 기능이 포함된 새로운 self-contained application을 제시합니다. `dpm`을 사용해 각 section의 code를 불러올 수 있습니다. 예를 들면 다음과 같습니다.

```bash
# Load the contract templates example
dpm new intro-contracts --template daml-intro-contracts

# Load the choices example
dpm new intro-choices --template daml-intro-choices
```
