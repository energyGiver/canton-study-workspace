## 도움 요청

위 topic guide로 issue가 해결되지 않으면 다음을 이용하세요.

- **Self-service**: 이 troubleshooting guide와 [debugging tool](/appdev/tooling/debugging-tools) page를 검색합니다.
- **Community**: error message, redact한 log 및 environment detail(Validator ID, network, SDK/Splice version)과 함께 `#gsf-global-synchronizer-appdev`(Slack) 또는 [forum.canton.network](https://forum.canton.network/)에 게시합니다.

도움을 요청할 때 다음을 포함하세요.

- Validator ID 및 network(DevNet, TestNet 또는 MainNet)
- 실행 중인 Splice/SDK version
- 관련 log excerpt(private key, password 및 JWT token은 redact하고 error code, correlation ID 및 timestamp는 유지)
- issue 발생 시점과 최근 변경 사항을 담은 timeline
