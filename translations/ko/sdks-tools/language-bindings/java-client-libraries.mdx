# Java client library

Java client library는 gRPC Ledger API 사용을 단순화합니다. 사용 방법은 Java에서 Contract와 transaction을 다루는 방법을 참조하세요. 아래에서는 code architecture, 설치, reference material을 설명합니다.

## Overview

<div id="component-howtos-application-development-java-client-libraries-bindings-java">

Java client library인 `bindings-java`는 Ledger API generated class를 기반으로 한 Java idiomatic layer입니다. Ledger API 작업에 필요한 code를 단순화하며 gRPC Ledger API generated class와 상호작용하는 `toProto`와 `fromProto` method를 포함합니다.

</div>

또한 기본 Daml data type을 Java로 나타내는 class 집합을 제공합니다. Daml Codegen for Java는 이를 사용해 User-defined Daml code에 대응하는 Java code를 생성합니다.

이 library는 Java Package `com.daml.ledger.javaapi.data`에 구현됩니다.

## Install

Java client library의 사용 가능한 version은 Maven Central Repository에서 확인합니다.
