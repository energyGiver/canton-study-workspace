**Ledger API**는 Canton Participant Node의 기본 programmatic interface입니다. Application은 이를 사용해 Contract 생성과 Choice 실행 command를 submit하고 transaction stream을 read하며 Party와 Package를 관리합니다.

Ledger API는 같은 기반 service를 감싸는 gRPC와 HTTP 기반 JSON 두 protocol binding으로 노출됩니다. Stack에 맞는 binding을 선택합니다.

## 빠른 참조

| 속성 | gRPC | JSON |
|----------|------|------|
| Protocol | HTTP/2 + Protocol Buffers | HTTP/1.1 + JSON over REST |
| Default port | 5001 | 7575 |
| API version | v2, Canton 3.x | v2, Canton 3.x |
| Authentication | OIDC를 통한 JWT, RS256 | OIDC를 통한 JWT, RS256 |
| 적합한 용도 | Java, Scala, high-throughput Backend | TypeScript, browser client, scripting |

## gRPC Ledger API

다음이 필요하면 gRPC를 사용합니다.

- Streaming service인 `UpdateService`, `CommandCompletionService`, `StateService`의 전체 surface
- Java, Scala 또는 다른 gRPC 지원 language용 `protoc` 기반 type-safe code generation
- 고빈도 command submit 및 event subscription을 위한 가장 낮은 latency

Proto definition, request/response schema, Package history를 포함한 service별 전체 reference는 API Reference dropdown의 **[gRPC Ledger API Reference](/api-reference)**를 참조하세요.

Proto definition은 [Canton repository](https://github.com/digital-asset/canton/tree/main/community/ledger-api-proto/src/main/protobuf/com/daml/ledger/api/v2)에 있습니다.

## JSON Ledger API

다음이 필요하면 JSON을 사용합니다.

- gRPC client 없이 browser 또는 Node.js application에서 HTTP/REST access
- Ad-hoc tooling 및 scripting에 편리한 request/response 형식
- WebSocket 기반 streaming, JSON API가 gRPC streaming service에 해당하는 기능을 노출

모든 endpoint의 OpenAPI reference는 API Reference dropdown의 **[JSON Ledger API Reference](/api-reference)**를 참조하세요. Streaming endpoint의 AsyncAPI reference도 같은 dropdown에 있습니다.

Authentication, Party allocation, Contract 생성, query를 다루는 JSON API end-to-end walkthrough는 [Module 4, Canton and the JSON Ledger API](/appdev/modules/m4-json-api-tutorial)에 있습니다.

## 핵심 service

두 binding에서 같은 logical service surface를 사용할 수 있습니다.

- **CommandService** — Command를 submit하고 completion을 기다리는 synchronous service
- **CommandSubmissionService** + **CommandCompletionService** — Command를 asynchronous하게 submit하고 completion event를 consume
- **UpdateService** — Transaction 및 reassignment 같은 Ledger update stream
- **StateService** — Active Contract Set, ACS query
- **InteractiveSubmissionService** — External signing용 transaction 준비
- **PartyManagementService** — Party allocate 및 list, 3.x에서는 Admin API 아래에 있고 Ledger API에 노출되지 않음
- **PackageService** — DAR Package upload 및 query
