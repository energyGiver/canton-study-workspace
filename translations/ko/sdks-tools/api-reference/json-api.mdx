JSON API는 Canton Ledger API의 HTTP/REST interface를 제공합니다. Canton 3.x에서는 Participant Node에 직접 통합되어 JSON HTTP request를 gRPC Ledger API call로 변환합니다.

## 빠른 참조

| 속성 | 값 |
|----------|-------|
| **Protocol** | HTTP/1.1 + JSON |
| **Default port** | 7575 |
| **기반 API** | Ledger API v2, gRPC |
| **Authentication** | JWT Bearer token |

## JSON API 사용 시점

다음 경우 JSON API를 권장합니다.

- Browser 기반 Frontend 또는 web application을 개발하는 경우
- Language/framework가 gRPC보다 HTTP/JSON과 더 잘 동작하는 경우
- 개발 및 debugging에 curl, Postman 같은 간단한 tooling을 원하는 경우
- TypeScript/JavaScript Wallet SDK를 사용하는 경우

다음 경우 gRPC를 직접 사용합니다.

- High-throughput streaming에서 최대 성능이 필요한 경우
- Java를 사용하고 native gRPC 방식을 원하는 경우
- JSON으로 노출되지 않은 gRPC 전용 기능에 access해야 하는 경우

### Command submit

```bash
curl localhost:7575/v2/commands/submit-and-wait \
  -H "Content-Type: application/json" \
  -d '{
    "commands": [
      {
        "CreateCommand": {
          "createArguments": {
            "issuer": "<partyId>",
            "owner": "<partyId>",
            "name": "Example Asset Name"
          },
          "templateId": "#json-tests:Main:Asset"
        }
      }
    ],
    "userId": "ledger-api-user",
    "commandId": "example-app-create-1234",
    "actAs": ["<partyId>"],
    "readAs": ["<partyId>"]
  }'
```

그 밖의 submit endpoint로 전체 transaction을 반환하는 `/v2/commands/submit-and-wait-for-transaction`과 즉시 반환하는 `/v2/commands/async/submit`이 있습니다.

### Transaction streaming

JSON API는 `/v2/updates`의 streaming update에 HTTP POST와 WebSocket connection을 모두 지원합니다. WebSocket connection은 `daml.ws.auth` subprotocol을 사용합니다.

### Ledger End

`GET /v2/state/ledger-end`는 Participant의 최신 absolute offset을 반환합니다. 최신 state를 얻는 ACS query에서 `activeAtOffset` 값으로 사용하거나, pruning되지 않은 과거 offset을 전달해 특정 historical point의 state를 read합니다.

### Interactive Submission

External Party command submit은 표준 `submit-and-wait` flow 대신 두 endpoint를 사용합니다.

- `POST /v2/interactive-submission/prepare` — External Party가 Participant 밖에서 sign할 prepared transaction을 생성합니다.
- `POST /v2/interactive-submission/execute` — Sign된 prepared transaction을 Ledger 실행을 위해 Participant에 다시 submit합니다.

전체 external signing flow는 [Validator API](/sdks-tools/api-reference/splice-validator-api)를 참조하세요.

## Configuration

JSON API는 Participant Node configuration의 `http-ledger-api` section에서 설정합니다. cn-quickstart LocalNet deployment에는 미리 설정되어 있으며 `http://localhost:7575`에서 사용할 수 있습니다.

OpenAPI 및 AsyncAPI specification은 runtime에 사용할 수 있습니다.
