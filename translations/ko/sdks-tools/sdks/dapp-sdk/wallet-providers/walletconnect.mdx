WalletConnect는 Mobile/Cross-device Wallet을 dApp에 연결합니다. Wallet은 WalletConnect Wallet SDK를 통해 Canton support를 추가하고 dApp은 `WalletConnectAdapter`를 등록해 WalletConnect를 활성화합니다. 자세한 내용은 [Wallet discovery](/sdks-tools/sdks/dapp-sdk/guides/wallet-discovery)를 참조하세요.

## Wallet에 Canton support 추가

Canton Network support를 추가하려면 공식 WalletConnect 문서인 [WalletConnect: Canton chain support](https://docs.walletconnect.network/wallet-sdk/chain-support/canton)를 따르세요.

다른 integration path와 마찬가지로 Wallet은 runtime에 CIP-103을 준수해야 합니다.

## Production 고려사항

- Relay unavailable 상태와 session expiry를 안정적으로 처리합니다.

## 다음 단계
