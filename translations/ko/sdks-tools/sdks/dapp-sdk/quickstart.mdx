가장 짧게 동작하는 integration입니다. SDK를 설치하고 initialize한 뒤 User가 Wallet을 연결하게 하고 Party를 읽어 transaction을 제출합니다. High-level SDK만 사용하며 dApp 구축에 Provider API는 필요하지 않습니다.

<Steps>
<Step title="SDK 설치">
<Tabs>
  <Tab title="npm">
  ```shell
  npm install @canton-network/dapp-sdk
  ```
  </Tab>
  <Tab title="yarn">
  ```shell
  yarn add @canton-network/dapp-sdk
  ```
  </Tab>
  <Tab title="pnpm">
  ```shell
  pnpm add @canton-network/dapp-sdk
  ```
  </Tab>
</Tabs>
</Step>

<Step title="App load 시 initialize">
Application lifecycle 초기에 `init()`을 한 번 호출합니다. Default Wallet Adapter를 등록하고 Wallet picker를 열지 않은 채 이전 session을 조용히 복원합니다.

```typescript
import * as sdk from '@canton-network/dapp-sdk'

await sdk.init()
```
</Step>

<Step title="Wallet 연결">
"Connect wallet" button 같은 User action에 대한 응답으로 `connect()`를 호출합니다. Wallet picker가 열리고 authentication flow가 실행됩니다.

```typescript
async function onConnectClick() {
    const result = await sdk.connect()
    console.log('Connected:', result.isConnected)
}
```
</Step>

<Step title="연결된 Party 읽기">
연결 후 User가 Primary로 지정한 Account를 읽습니다.

```typescript
const account = await sdk.getPrimaryAccount()
console.log('Primary party:', account.partyId)
```
</Step>

<Step title="Transaction 제출">
`prepareExecute()`로 Daml command를 제출합니다. SDK가 transaction을 prepare하고 User에게 Wallet에서 approve/sign하도록 요청한 뒤 Ledger에 제출합니다.

```typescript
const account = await sdk.getPrimaryAccount()

await sdk.prepareExecute({
    commands: [
        {
            CreateCommand: {
                templateId: '#AdminWorkflows:Canton.Internal.Ping:Ping',
                createArguments: {
                    id: `ping-${Date.now()}`,
                    initiator: account.partyId,
                    responder: account.partyId,
                },
            },
        },
    ],
})
```

<Note>
이 example은 built-in `Ping` Template을 사용해 round-trip이 동작하는지 확인합니다. 실제 dApp에서는 자체 Daml Package의 command를 제출하세요. 자세한 내용은 [Party 및 transaction](/sdks-tools/sdks/dapp-sdk/guides/parties-and-transactions)을 참조하세요.
</Note>
</Step>

<Step title="Disconnect 처리">
User가 session을 종료할 수 있게 합니다.

```typescript
async function onDisconnectClick() {
    await sdk.disconnect()
}
```
</Step>
</Steps>
