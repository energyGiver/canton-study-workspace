dApp SDK는 UI가 Wallet state와 동기화되도록 event를 emit합니다. `on*` function으로 subscribe하고 대응하는 `off*` function으로 unsubscribe합니다. 사용 example은 [Event 처리](/sdks-tools/sdks/dapp-sdk/guides/handle-events)를 참조하세요.

## `onStatusChanged(handler)` / `offStatusChanged(handler)`

Connection status 또는 session state가 변경될 때 발생합니다.

| Payload field            | Type      | Description                            |
| ------------------------ | --------- | -------------------------------------- |
| `connection.isConnected` | `boolean` | 현재 session의 active 여부입니다. |

## `onAccountsChanged(handler)` / `offAccountsChanged(handler)`

Account가 추가/제거되거나 Primary Account가 변경될 때 발생합니다.

| Payload    | Type        | Description                 |
| ---------- | ----------- | --------------------------- |
| `accounts` | `Account[]` | 현재 Party 집합입니다. |

## `onTxChanged(handler)` / `offTxChanged(handler)`

`prepareExecute`로 제출한 transaction이 lifecycle을 거칠 때 발생합니다.

| Payload field      | Type                                              | Description                                 |
| ------------------ | ------------------------------------------------- | ------------------------------------------- |
| `status`           | `'pending' \| 'signed' \| 'executed' \| 'failed'` | 현재 transaction state입니다.               |
| `payload.updateId` | `string`                                          | `executed` 시 존재하는 Ledger update ID입니다. |
