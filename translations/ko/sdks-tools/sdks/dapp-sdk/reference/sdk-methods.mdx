## Lifecycle

### `init(options?)`

Wallet Adapter를 등록하고 Wallet picker를 열지 않은 채 이전 session을 조용히 복원합니다. Application lifecycle 초기에 한 번 호출합니다.

| Parameter                    | Type        | Description                                                              |
| ---------------------------- | ----------- | ------------------------------------------------------------------------ |
| `options.additionalAdapters` | `Adapter[]` | Default와 함께 등록할 추가 Adapter입니다.                                |
| `options.defaultAdapters`    | `Adapter[]` | Default Remote Wallet list를 교체합니다. 등록하지 않으려면 `[]`를 전달합니다. |

### `connect()`

Wallet picker를 열고 connection을 생성하며 필요하면 authentication flow를 실행합니다. Connection 성공 여부를 나타내는 result를 반환합니다.

### `disconnect()`

dApp과 Wallet 사이의 session을 종료합니다.

## Status

### `status()`

현재 connection의 Network 및 session 관련 정보를 반환합니다.

### `isConnected()`

Login flow를 trigger하지 않고 User 연결 여부를 반환합니다. Page load 시 안전하게 호출할 수 있습니다.

### `getActiveNetwork()`

Wallet이 연결된 Network의 상세 정보를 반환합니다.

## Accounts

### `listAccounts()`

User가 접근할 수 있는 모든 Party를 반환합니다.

### `getPrimaryAccount()`

User가 Primary로 지정한 Account를 반환합니다.

## Signing 및 transaction

### `signMessage(message)`

Primary Account로 임의 string에 서명합니다.

| Parameter | Type     | Description          |
| --------- | -------- | -------------------- |
| `message` | `string` | 서명할 message입니다. |

### `prepareExecute(commands)`

Daml transaction을 prepare하고 signature를 요청한 뒤 실행합니다.

| Parameter  | Type                      | Description                   |
| ---------- | ------------------------- | ----------------------------- |
| `commands` | `{ commands: Command[] }` | 실행할 Daml command입니다. |

### `ledgerApi(request)`

Canton JSON Ledger API로 인증된 request를 proxy합니다.

| Parameter               | Type     | Description                            |
| ----------------------- | -------- | -------------------------------------- |
| `request.requestMethod` | `string` | `'GET'` 같은 HTTP method입니다.        |
| `request.resource`      | `string` | `'/v2/version'` 같은 Ledger API path입니다. |

## Provider 접근

### `getConnectedProvider()`

Active discovery session의 raw CIP-103 Provider를 반환하고 연결되지 않았다면 `null`을 반환합니다. `provider.request(...)` 직접 call이나 Provider-level event에 사용합니다.
