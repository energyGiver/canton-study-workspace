dApp SDK는 UI가 Wallet state와 동기화될 수 있도록 event를 emit합니다. `on*` function으로 subscribe하고 component가 unmount될 때 항상 대응하는 `off*` function으로 unsubscribe하세요.

전체 event list와 payload는 [Event reference](/sdks-tools/sdks/dapp-sdk/reference/events)를 참조하세요.

## Connection status change 처리

Connection status 또는 session state가 변경되면 `onStatusChanged`가 발생합니다.

```typescript
const handler = (status) => {
    console.log('Connected:', status.connection.isConnected)
}

sdk.onStatusChanged(handler)
// Later:
sdk.offStatusChanged(handler)
```

## Account change 처리

Account가 추가/제거되거나 Primary Account가 변경되면 `onAccountsChanged`가 발생합니다. Primary Party를 cache하지 말고 다시 읽으세요.

```typescript
sdk.onAccountsChanged((accounts) => {
    const primary = accounts.find((a) => a.primary)
})
```

## Transaction tracking

`prepareExecute`로 제출한 transaction이 `pending`, `signed`, `executed`, `failed` lifecycle을 거칠 때 `onTxChanged`가 발생합니다.

```typescript
sdk.onTxChanged((tx) => {
    if (tx.status === 'executed') {
        console.log('Update ID:', tx.payload.updateId)
    }
})
```

## Listener 정리

Component가 unmount될 때 모든 listener를 제거하세요. 제거하지 않은 listener는 memory leak과 오래된 UI update를 유발합니다.

```typescript
const handler = (status) => setConnected(status.connection.isConnected)

sdk.onStatusChanged(handler)

// On unmount:
sdk.offStatusChanged(handler)
```
