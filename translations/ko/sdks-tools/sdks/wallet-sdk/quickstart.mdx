## Prerequisites

- Node.js v18 이상
- 실행 중인 Canton Validator Node. Self-hosted 또는 Node-as-a-Service provider를 사용할 수 있습니다. 어떤 network의 Validator도 사용할 수 있습니다. [Splice LocalNet](/sdks-tools/development-tools/localnet)은 development와 test에 편리하며 DevNet, TestNet 또는 MainNet Validator도 사용할 수 있습니다.

## Installation

Wallet SDK는 NPM registry package로 제공되며 선호하는 package manager로 install할 수 있습니다.

<Tabs>
  <Tab title="npm">
  <CantonIntegrationsWalletSdkDownloadL14 />
  </Tab>
  <Tab title="yarn">
  <CantonIntegrationsWalletSdkDownloadL20 />
  </Tab>
  <Tab title="pnpm">
  ```shell
  pnpm add @canton-network/wallet-sdk
  ```
  </Tab>
</Tabs>

dApp만 개발한다면 bundle size가 더 작고 browser 사용에 optimized된 dApp SDK를 사용할 수 있습니다. dApp SDK install 방법은 다음과 같습니다.

    <Tabs>
    <Tab title="npm">
        ```shell
        npm install @canton-network/dapp-sdk
        ```
    </Tab>
    <Tab title="yarn">
        ```shell
        yarn add @canton-network/dapp-sdk
        ```
    </Tab>
    <Tab title="pnpm">
        ```shell
        pnpm add @canton-network/dapp-sdk
        ```
    </Tab>
</Tabs>

두 SDK는 같은 underlying core package를 사용합니다. Transaction visualization 또는 hash verification처럼 code 일부만 필요하면 해당 package를 독립적으로 사용할 수 있습니다.

## Configuration

SDK에는 authentication, ledger access 및 Token Standard connectivity configuration이 필요합니다. Splice LocalNet을 사용하는 local development에서는 built-in default를 사용할 수 있습니다.

<DamlDocsSdksToolsSdksWalletSdkL69 />

Production 또는 LocalNet이 아닌 environment로 이동할 때는 해당 endpoint를 가리키는 custom factory function이 필요합니다. 자세한 내용은 [Configuration](/sdks-tools/sdks/wallet-sdk/using-the-sdk/configuration)을 참조하세요.
