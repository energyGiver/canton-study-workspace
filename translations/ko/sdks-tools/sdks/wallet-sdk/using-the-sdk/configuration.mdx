## Wallet SDK Configuration

다음 code example은 Wallet SDK initialization 방법을 보여줍니다. 변경하지 않은 [Localnet](https://docs.canton.network/sdks-tools/development-tools/localnet) instance와 함께 사용할 수 있는 default config입니다.
Script, code 및 deployment를 다른 environment로 migrate하면 default configuration을 사용할 수 없으므로 registry, auth 등의 value를 변경해야 합니다.

Auth config와 ledgerClientUrl을 설정하는 static configuration initialization은 다음과 같습니다.

```typescript
import { SDK, localNetStaticConfig } from "@canton-network/wallet-sdk";

export default async function () {
  const sdk = await SDK.create({
    auth: {
      method: "self_signed",
      issuer: "unsafe-auth",
      credentials: {
        clientId: "ledger-api-user",
        clientSecret: "unsafe",
        audience: "https://canton.network.global",
        scope: "",
      },
    },
    ledgerClientUrl: new URL("http://localhost:2975"),
    token: {
      registries: [
        new URL("http://localhost:2000/api/validator/v0/scan-proxy"),
      ],
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
    },
    amulet: {
      scanApiUrl: localNetStaticConfig.LOCALNET_SCAN_API_URL,
      auth: TOKEN_PROVIDER_CONFIG_DEFAULT,
      registryUrl: localNetStaticConfig.LOCALNET_REGISTRY_API_URL,
    },
    asset: {
      registries: [localNetStaticConfig.LOCALNET_REGISTRY_API_URL],
      auth: TOKEN_PROVIDER_CONFIG_DEFAULT,
    },
  });

  // OR, you can defer loading config by calling .extend()

  const basicSDK = await SDK.create({
    auth: {
      method: "self_signed",
      issuer: "unsafe-auth",
      credentials: {
        clientId: "ledger-api-user",
        clientSecret: "unsafe",
        audience: "https://canton.network.global",
        scope: "",
      },
    },
    ledgerClientUrl: new URL("http://localhost:2975"),
  });

  // Extend with token namespace
  const tokenExtendedSDK = await basicSDK.extend({
    token: {
      validatorUrl: new URL("http://localhost:2000/api/validator"),
      registries: [
        new URL("http://localhost:2000/api/validator/v0/scan-proxy"),
      ],
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
    },
  });

  // Can extend further with more namespaces
  const fullyExtendedSDK = await tokenExtendedSDK.extend({
    amulet: {
      validatorUrl: localNetStaticConfig.LOCALNET_APP_VALIDATOR_URL,
      scanApiUrl: localNetStaticConfig.LOCALNET_SCAN_API_URL,
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
      registryUrl: localNetStaticConfig.LOCALNET_REGISTRY_API_URL,
    },
  });
}
```

Namespace initialization은 나중으로 미룰 수 있으므로 Ledger API capability와 default namespace만 있는 basicSDK를 먼저 initialize할 수 있습니다.
다음은 basicSDK initialization과 namespace extension 예제입니다.

```typescript
import { SDK, localNetStaticConfig } from "@canton-network/wallet-sdk";

export default async function () {
  const basicSDK = await SDK.create({
    auth: {
      method: "self_signed",
      issuer: "unsafe-auth",
      credentials: {
        clientId: "ledger-api-user",
        clientSecret: "unsafe",
        audience: "https://canton.network.global",
        scope: "",
      },
    },
    ledgerClientUrl: new URL("http://localhost:2975"),
  });

  // Extend with token namespace
  const tokenExtendedSDK = await basicSDK.extend({
    token: {
      validatorUrl: new URL("http://localhost:2000/api/validator"),
      registries: [
        new URL("http://localhost:2000/api/validator/v0/scan-proxy"),
      ],
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
    },
  });

  // Can extend further with more namespaces
  const fullyExtendedSDK = await tokenExtendedSDK.extend({
    amulet: {
      validatorUrl: localNetStaticConfig.LOCALNET_APP_VALIDATOR_URL,
      scanApiUrl: localNetStaticConfig.LOCALNET_SCAN_API_URL,
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
      registryUrl: localNetStaticConfig.LOCALNET_REGISTRY_API_URL,
    },
  });
}
```

Wallet SDK를 initialize하는 다른 방법은 Provider를 사용하는 것입니다. Provider는 최종적으로 Ledger(JSON LAPI)와 interaction하는 abstraction이며 dApp consumer, direct ledger user 또는 Wallet Connect 같은 alternative transport channel에 맞게 구현할 수 있습니다.

```typescript
import { SDK, localNetStaticConfig } from "@canton-network/wallet-sdk";

// Notice that `auth` and `ledgerClientUrl` are no longer needed
// when supplying sdk with custom provider
const sdk = await SDK.create(config, provider);
```

## How do I validate my configurations?

정확한 URL과 port를 사용하는지 확인하기 어려울 수 있습니다. 다음 curl 및 gcurl command로 expected output과 비교해 validate할 수 있습니다.

**my-json-ledger-api**는 `curl http://${my-json-ledger-api}/v2/version`으로 식별할 수 있으며 다음과 유사한 JSON을 생성해야 합니다.

```json
{
  "version": "3.4.12-SNAPSHOT",
  "features": {
    "experimental": {
      "staticTime": {
        "supported": false
      },
      "commandInspectionService": {
        "supported": true
      }
    },
    "userManagement": {
      "supported": true,
      "maxRightsPerUser": 1000,
      "maxUsersPageSize": 1000
    },
    "partyManagement": {
      "maxPartiesPageSize": 10000
    },
    "offsetCheckpoint": {
      "maxOffsetCheckpointEmissionDelay": {
        "seconds": 75,
        "nanos": 0,
        "unknownFields": {
          "fields": {}
        }
      }
    },
    "packageFeature": {
      "maxVettedPackagesPageSize": 100
    }
  }
}
```

Field는 configuration에 따라 달라질 수 있습니다.

**my-validator-app-api**는 `curl ${api}/version`으로 식별할 수 있으며 다음과 유사한 output을 생성해야 합니다.

```json
{ "version": "0.4.15", "commit_ts": "2025-09-05T11:38:13Z" }
```

**my-scan-proxy-api**는 Validator API 내부 API이며 `${my-validator-app-api}/v0/scan-proxy`로 정의할 수 있습니다.

**my-registry-api**는 사용할 token의 registry입니다. Canton Coin에는 **my-scan-proxy-api**를 사용할 수 있지만 다른 Token Standard token은 신뢰할 수 있는 source에서 API를 확인해야 합니다.

## Configuring auth

Wallet SDK는 auth가 포함된 Provider 또는 LedgerClientUrl과 TokenProviderConfig를 받을 수 있습니다. 예제는 self-signed token으로 LocalNet에 연결하는 default TokenProviderConfig를 제공합니다.

```javascript
{
method: 'self_signed',
issuer: 'unsafe-auth',
credentials: {
   clientId: 'ledger-api-user',
   clientSecret: 'unsafe',
   audience: 'https://canton.network.global',
   scope: '',
},
}
```

LocalNet의 일부 audience value는 "[https://canton.network.global](https://canton.network.global)"과 일치하도록 조정해야 합니다. 구체적으로 `LEDGER_API_AUTH_AUDIENCE` 및 `VALIDATOR_AUTH_AUDIENCE`입니다.

LocalNet setup을 production 또는 client-facing environment로 upgrade할 때는 Ledger API 및 기타 service에 적절한 authentication을 추가해야 합니다. Community contribution에는 Okta와 Keycloak [OIDC](/global-synchronizer/deployment/oidc-providers)가 있으며 다른 TokenProviderConfig를 사용해 SDK에 쉽게 configure할 수 있습니다. Token fetch는 다음 programmatic method를 지원합니다.

> 1.  \`static\`: 고정된 in-memory token입니다. Compatibility 목적으로만 사용하며 token이 expire되면 완전히 동작하지 않습니다.
> 2.  \`self_signed\`: Development 용도로만 사용하며 HMAC256 self-signed token을 허용하는 Canton setup에 사용합니다.
> 3.  \`client_credentials\`: OAuth 2.0을 통해 "machine-to-machine" token을 programmatically acquire합니다.

```javascript
export type TokenProviderConfig =
   | {
         method: 'static'
         token: string
      }
   | {
         method: 'self_signed'
         issuer: string
         credentials: ClientCredentials
      }
   | {
         method: 'client_credentials'
         configUrl: string
         credentials: ClientCredentials
      }

export interface ClientCredentials {
 clientId: string
 clientSecret: string
 scope: string | undefined
 audience: string | undefined
}
```

## Environment-specific endpoints

LocalNet이 아닌 각 environment에는 서로 다른 connection endpoint가 필요합니다. 다음 connection parameter를 configure합니다.

- **JSON Ledger API URL**: Validator Participant의 HTTP/JSON API endpoint
- **gRPC Admin API URL**: Participant administration용 gRPC endpoint
- **Scan API URL**: Direct 또는 BFT Scan proxy를 통한 Scan service endpoint
- **Auth token**: OIDC Provider가 발급한 유효 JWT token
- **Validator API URL**: Validator app의 REST API endpoint. Token/Amulet namespace에서는 선택 항목이며 제공하지 않으면 Scan API를 사용합니다.

전체 예제는 Wallet SDK repository의 [config template](https://github.com/canton-network/wallet-gateway/blob/main/docs/wallet-integration-guide/examples/snippets/config-template.ts)을 참조하세요.
