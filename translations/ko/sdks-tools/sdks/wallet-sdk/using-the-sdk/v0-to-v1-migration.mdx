Configure() 및 connect() pattern을 제거하고 static configuration 또는 Ledger API capability가 있는 Provider를 전달하도록 변경했습니다.

Auth config와 ledgerClientUrl을 제공하는 static configuration initialization은 다음과 같습니다.

```typescript
import { SDK, localNetStaticConfig } from "@canton-network/wallet-sdk";

export default async function () {
  const sdk = await SDK.create({
    auth: {
      method: "self_signed",
      issuer: "unsafe-auth",
      credentials: {
        clientId: "ledger-api-user",
        clientSecret: "unsafe",
        audience: "https://canton.network.global",
        scope: "",
      },
    },
    ledgerClientUrl: new URL("http://localhost:2975"),
    token: {
      registries: [
        new URL("http://localhost:2000/api/validator/v0/scan-proxy"),
      ],
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
    },
    amulet: {
      scanApiUrl: localNetStaticConfig.LOCALNET_SCAN_API_URL,
      auth: TOKEN_PROVIDER_CONFIG_DEFAULT,
      registryUrl: localNetStaticConfig.LOCALNET_REGISTRY_API_URL,
    },
    asset: {
      registries: [localNetStaticConfig.LOCALNET_REGISTRY_API_URL],
      auth: TOKEN_PROVIDER_CONFIG_DEFAULT,
    },
  });

  const myParty = global.EXISTING_PARTY_1;

  await sdk.token.utxos.list({ partyId: myParty });

  await sdk.amulet.traffic.status();

  // OR, you can defer loading config by calling .extend()

  const basicSDK = await SDK.create({
    auth: {
      method: "self_signed",
      issuer: "unsafe-auth",
      credentials: {
        clientId: "ledger-api-user",
        clientSecret: "unsafe",
        audience: "https://canton.network.global",
        scope: "",
      },
    },
    ledgerClientUrl: new URL("http://localhost:2975"),
  });

  // Extend with token namespace
  const tokenExtendedSDK = await basicSDK.extend({
    token: {
      validatorUrl: new URL("http://localhost:2000/api/validator"),
      registries: [
        new URL("http://localhost:2000/api/validator/v0/scan-proxy"),
      ],
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
    },
  });

  // Now token namespace is available
  await tokenExtendedSDK.token.utxos.list({ partyId: myParty });

  // Can extend further with more namespaces
  const fullyExtendedSDK = await tokenExtendedSDK.extend({
    amulet: {
      validatorUrl: localNetStaticConfig.LOCALNET_APP_VALIDATOR_URL,
      scanApiUrl: localNetStaticConfig.LOCALNET_SCAN_API_URL,
      auth: global.TOKEN_PROVIDER_CONFIG_DEFAULT,
      registryUrl: localNetStaticConfig.LOCALNET_REGISTRY_API_URL,
    },
  });

  // Now both token and amulet are available
  await fullyExtendedSDK.token.utxos.list({ partyId: myParty });
  await fullyExtendedSDK.amulet.traffic.status();
}
```

Provider initialization: Provider는 최종적으로 Ledger(JSON LAPI)와 interaction하는 abstraction이며 dApp consumer, direct ledger user 또는 Wallet Connect 같은 alternative transport channel에 맞게 구현할 수 있습니다.

```javascript
// Notice that `auth` and `ledgerClientUrl` are no longer needed
// when supplying sdk with custom provider
const sdk = await SDK.create(config, provider);
```

## Namespace changes

Business context에 따라 service layer를 적절히 분리하기 위해 controller를 제거하고 namespace로 교체했습니다. SDK를 initialize하면 users, keys, ledger 및 party namespace에 접근할 수 있습니다. Amulet, token, asset 및 events namespace는 `.extend()` method를 통해 별도 config로 initialize할 수 있습니다.

## Removed functionality

다음 method가 제거됐습니다.

`sdk.connect()`은 SDK 생성 시 연결되므로 더 이상 필요하지 않습니다. `sdk.connectAdmin()`도 필요하지 않으며 admin operation은 ledger namespace에서 제공되고 right는 token에서 추출합니다. `sdk.connectTopology()`도 더 이상 필요하지 않습니다. gRPC endpoint가 제거되고 Ledger API endpoint로 교체됐습니다. `sdk.setPartyId()` 대신 각 operation에 `partyId`를 명시적으로 전달합니다.

<div className="before-after">

```javascript
sdk.setPartyId(myPartyId);
const holdingTransactionsmyPartyId =
  await sdk.tokenStandard?.listHoldingTransactions();
sdk.setPartyId(myPartyId2);
const holdingTransactionsmyPartyId2 =
  await sdk.tokenStandard?.listHoldingTransactions();
```

---

```javascript
const holdingTransactionsmyPartyId = await token.holdings(myPartyId);
const holdingTransactionsmyPartyId2 = await token.holdings(myPartyId2);
```

</div>

v0의 controller와 SDK는 stateful이었습니다. v1에서는 각 function에 Party information을 명시적으로 전달해야 합니다. 이를 통해 여러 Party로 action할 수 있고 concurrent use에서 thread safety를 확보합니다.

## Keys and events

**keys** namespace는 basic SDK에서 항상 사용할 수 있습니다. Standalone key-pair helper 대신 사용하세요.

| v0                | v1                    |
| ----------------- | --------------------- |
| `createKeyPair()` | `sdk.keys.generate()` |

**events** namespace는 `userLedger`의 ledger update 및 completion subscription을 대체합니다. `amulet`, `token`, `asset`과 마찬가지로 creation 시점 또는 `.extend()`를 통해 configure하는 extended namespace입니다.

| v0                                      | v1                       |
| --------------------------------------- | ------------------------ |
| `sdk.userLedger.subscribeToUpdates`     | `sdk.events.updates`     |
| `sdk.userLedger.subscribeToCompletions` | `sdk.events.completions` |

모든 namespace의 전체 method map은 [migration cheat sheet](/sdks-tools/sdks/wallet-sdk/using-the-sdk/v0-to-v1-migration/migration-cheat-sheet)를 참조하세요.
