[Wallet SDK](https://github.com/canton-network/wallet-gateway/tree/main/sdk/wallet-sdk)는 Ledger API를 통해 Canton Network와 interaction하는 TypeScript library를 제공합니다. Wallet과 exchange에서 자주 사용하는 Party 생성, Token Standard transfer 및 data read 같은 pattern을 더 쉽게 구현하도록 돕습니다. SDK는 Canton Network token과 interaction하고 External Party Wallet을 manage해야 하는 Wallet Provider, exchange 및 application developer를 위해 설계됐습니다.

## What the SDK provides

- **Transaction preparation**: Token Standard를 사용해 Canton Network transaction을 build하고 sign합니다.
- **Token Standard client**: Canton Network Token Standard API와 interaction합니다.
- **Transaction history parsing**: Ledger update를 구조화된 deposit/withdrawal record로 parse합니다.
- **Configuration management**: LocalNet, DevNet, TestNet 및 MainNet 등 여러 environment에 연결합니다.
- **External signing support**: External Party signing workflow를 위한 transaction을 prepare합니다.
