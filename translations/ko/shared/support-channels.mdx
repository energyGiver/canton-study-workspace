## Support 요청에 포함할 내용

효과적인 지원을 받으려면 다음 정보를 포함하세요.

### 개발 문제

- Daml/Canton version
- Code snippet 또는 최소 재현 예제
- Error message와 전체 stack trace
- 기대한 결과와 실제로 발생한 결과

### 운영 문제

| 정보 | 필요한 이유 |
|-------------|------------|
| **Validator ID** | Node 식별 |
| **Network** | DevNet/TestNet/MainNet 확인 |
| **Splice version** | Compatibility 판단 |
| **Infrastructure** | Docker/K8s 및 cloud provider 확인 |
| **Logs** | 관련 error log 확인 |
| **Timeline** | 문제 시작 시점 확인 |

### Template

```
Environment:
- Network: [DevNet/TestNet/MainNet]
- Splice Version: [e.g., 0.5.4]
- Canton Version: [e.g., 3.4.x]
- Deployment: [Docker Compose/Kubernetes]
- Cloud Provider: [AWS/GCP/Azure/On-prem]

Issue:
[Clear description of the problem]

Expected Behavior:
[What should happen]

Actual Behavior:
[What actually happens]

Steps to Reproduce:
1. ...
2. ...

Relevant Logs:
[Sanitized logs - remove secrets/keys]

Additional Context:
[Any other relevant information]
```

<Warning>
Log를 공유하기 전에 항상 private key, JWT, password 및 기타 sensitive information을 제거하세요.
</Warning>
